## 无项目（`canvas.projectId === ''`）空态诊断

首启路径：`readSessionState().currentDir === null` → `getActiveProjectDir()` 抛 INVALID_ARGUMENT → `canvas:get` 兜底返回空画布。

已正确防护、无需改：`canvas:get` 兜底不白屏；`CaptureBar` 按 projectId 不渲染；`ProjectNav` 空库文案；`style:upgrade-diff` 无项目返回 noBrief；`project:active-session` 读态返回 `{sessionId:null}`。

真 bug（P0）：无项目仍可发消息。`StudioApp.handleSend` 无 projectId 守卫；`activeSession(session.id)` 写态在主进程抛 INVALID_ARGUMENT 被 catch 吞掉（StudioApp.tsx L456-461 + main.ts L433）；Agent 随后调用的 MCP 工具全部经 `getActiveProjectDir()` 抛错。后果 = 孤儿 opencode 会话 + 全工具失败 + 烧 token。

显示失真（P1）：
- 底栏状态条全硬编码（StudioApp.tsx L1005-1033）：火山方舟绿点、`10.203.3.52:8000/:8001/:8002`、镜头批量 12/18、「✓ Harness 校验 30 项」、「2 分钟前自动保存」——无项目/无 Key/无 ComfyUI 时照显。
- 顶栏标题「未命名项目」、STAGE 0 恒为 cur 紫 pill（defaultCur 兜底 '0'）。
- 中栏空态文案「在下方输入你的想法」（CanvasBoard.tsx L573-577）与 STAGE 0 empty 文案（Stage0View.tsx L285-291）都把用户导向对话，而对话在无项目时必失败；`useCaptureFacts` 的 loadError 被 EmptyStage0 丢弃。
