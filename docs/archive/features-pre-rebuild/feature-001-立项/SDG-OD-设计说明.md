## 2. 视觉规范（实际落地）

- 主背景：`#FAFAFE`（Tailwind `bg-canvas`）
- 主强调色：紫罗兰 `#6C5CE7`（`violet` / `violet-soft` 浅紫底）
- 状态色：成功绿 `#2BB673`、琥珀 `#E8A93C`、危险红 `#E05A52`
- 卡片：白底、圆角 12px、细边框 + 轻阴影（`shadow-card`）
- 字体：系统默认无衬线；标题 14-16px 加粗，正文 12-14px

## 3. 关键交互

| 元素 | 交互 |
| :-- | :-- |
| 画布节点 | active：紫色描边+外发光+脉冲；done：绿描边+✓；pending：灰半透明 |
| 节点连线 | 上游 done 后连线变绿 |
| 确认门 | 紫色加粗边框；校验项 ✓/✗；「展开详情」折叠区；确认/否决两按钮 |
| 对话输入 | Enter 发送、Shift+Enter 换行；发送中按钮禁用 |
| 背景档案 | 等宽字体文本域；琥珀色「事实 · AI 不可篡改」标记；锁定后按钮变绿 |
| 画布缩放 | ResizeObserver 监听，宽度不足时 scale 等比缩小（基准内容宽 992px） |
