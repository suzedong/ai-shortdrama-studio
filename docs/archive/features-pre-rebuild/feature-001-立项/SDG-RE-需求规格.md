# SDG-RE-需求规格 · feature-001-立项

> **[反向补录]** 本需求规格基于 2026-10-03 的代码现状反向编写，描述的是「代码已实现了什么」，不是「应该实现什么」。
>
> 对应架构文档：[短剧Agent平台设计.md](../../../短剧Agent平台设计.md) §2.6 立项阶段

## 1. 背景与定位

立项是短剧生产链路的第 0 阶段，产出项目的"宪法"：选题诊断、立项五要素、视觉风格、故事背景档案。本 Feature 实现立项阶段的桌面端交互闭环与 Agent 通道。

## 2. 用户与场景

- **用户**：短剧创作者（个人/小团队）
- **场景**：创作者在桌面应用中新建项目，用一句话描述创意，主控 Agent 自动检索分析并推进多轮确认，最终在本地生成项目文件并录入故事背景事实

## 3. 功能需求（代码已实现项）

### FR-1 三栏应用框架

- 顶部标题栏（traffic-light 占位、项目标题、模型信息、用户头像）
- 左栏：项目库（`ProjectSidebar`）
- 中间：立项画布（`StageCanvas`）
- 右栏：确认门卡片 + 主控 Agent 对话区（`ChatPanel`）
- 底部状态条（模型矩阵、连接状态、Harness 信息）

### FR-2 项目库展示

- 展示 3 个硬编码示例项目（安妮的夏天/旧港往事/未命名项目 2），含名称、描述、彩色首字图标
- 当前项目高亮（紫色底 + 绿点）

### FR-3 立项画布

- 线性展示 4 个节点：创意输入 → 选题诊断 → 立项单 → 故事背景档案
- 节点三态：`active`（紫色描边+光晕+脉冲）/ `done`（绿色描边+✓）/ `pending`（灰色半透明）
- 节点间连线，已完成节点的连线变绿
- 节点正文区支持结构化详情（`detail`），无详情时显示副标题
- 画布宽度不足时整链等比缩小（scale = min(1, 可用宽/992)），窗口 resize 时重算

### FR-4 创意提交与选题诊断

- 用户在对话区输入创意（Enter 发送、Shift+Enter 换行）
- 主进程调用火山方舟生成结构化选题诊断；未配置密钥或调用失败时降级 mock
- 诊断返回后：创意输入节点 done（显示创意原文）、选题诊断节点 active（显示前 3 个对标案例）、立项单节点预填五要素、弹出确认门 0-a

### FR-5 五要素自动推导

`deriveFiveElements(idea, diagnosis)` 规则：

- **题材**：关键词匹配 → 校园恋爱 / 都市情感 / 古装言情 / 悬疑推理
- **平台**：诊断案例中平台出现频率 Top 3；无则默认抖音、红果、小红书
- **单集时长**：正则提取"N秒/N分钟"；无则默认 90 秒
- **集数**：正则提取"N集"；无则默认 8 集
- **风格基调**：关键词匹配 → 日系清新·清凉温馨 / 甜宠高糖·强情绪 / 悬疑烧脑·快节奏 / 清新治愈

### FR-6 多轮确认门

- **0-a 选题诊断确认**：summary 为真实诊断结论；校验项动态生成（对标案例数 ≥3、合规 ≥2、洞察长度 >10）；可展开看完整对标案例表/用户洞察/钩子模式/合规要点
- **0-b 五要素确认**：summary 为五要素字符串；确认后触发视觉风格推荐
- **0-c 视觉风格确认**：由火山方舟基于五要素生成；校验项为形态匹配、锚词表 ≥8 词、推荐理由充分；可展开看 L2 锚词表/L1 世界观锚/锚点词/推荐理由
- 每门均有「确认放行」「否决/重做」；否决后关闭确认门

### FR-7 视觉风格 Agent 推荐

主进程向火山方舟发送五要素，返回形态、主画风、L2 锚词表、L1 世界观锚、质感配方、锚点词、推荐理由；失败降级 mock。

### FR-8 项目本地持久化

0-c 确认后，写入 `~/Documents/ai-shortdrama-studio/project-{时间戳}/`：

- `manifest.json`：五要素 + 视觉风格 + createdAt
- `brief.json`：version + 五要素 + 视觉风格 + benchmarkSummary + conclusion

写入成功后顶栏与底栏显示保存状态。随后背景档案节点激活。

### FR-9 故事背景档案录入

- 右栏出现档案录入组件，预置字段模板（人物档案/地理关系/时间线/季规划边界）
- 带「事实 · AI 不可篡改」标记
- 「锁定档案」后背景节点变 done，显示字数
