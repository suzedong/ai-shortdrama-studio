## 2. 画布三阶段布局

立项与故事两行之下新增第三行（自动布局，不可拖拽）：

```
STAGE 0 · 立项
[创意输入] ─ [选题诊断] ─ [立项单] ─ [故事背景档案]

STAGE 1 · 故事创作
[故事大纲] ─ [人物小传]

STAGE 2 · 剧本分镜
[分场] ─ [台词] ─ [分镜表]
```

| 元素 | 规范 |
|---|---|
| 组标签 | 行左上 `text-xs text-muted uppercase tracking-wide`：STAGE 0 / 1 / 2（沿用 StageCanvas 既有渲染） |
| 节点卡 | w-56 白卡 + 序号/✓ 徽标；active 紫描边 ring pulse、done 绿描边、pending 灰 |
| 组间 | 不连线，纵向 `space-y-10` + 组标签分隔 |
| 缩放 | 按最宽行动态缩放（三行中最宽为立项行 4 节点）；进入 STAGE 2 前第三行三节点灰态可见 |
| 节点详情 | 分场：`N 场 · 约 Xs`；台词：`M 句对白`；分镜表：`J 镜 · Xs`（画布节点 line-clamp 摘要） |

## 3. 新增卡片视觉

全部嵌于 Agent 白卡内（与 OutlineCard / ProfilesCard 同容器），360px 右栏不溢出、长文本 `whitespace-pre-wrap break-words`。

### 3.1 进入剧本分镜 CTA（ScriptEntryCta，右栏顶部）

沿用 StoryEntryCta 样式：白卡 `rounded-xl border shadow-card`，左侧标题「故事已完成」+ 副文案「进入剧本分镜，编剧 Agent 将拆分场次」，右侧紫底按钮「进入剧本分镜」。点击后卡片消失。

### 3.2 分场卡（ScenesCard）

- 顶部：`第一集 · 分场（N 场）` 小节标题。
- 每场一个分隔块（`divide-y`）：
  - 首行：`场{n} {slug}` 加粗 + 徽标 `（内/日）`（紫底淡色小字）；右侧 `约 {estSeconds}s` muted。
  - 两行 label/值网格：地点 / 出场（角色名顿号连接）/ 情绪 / 梗概。
  - 节拍：`节拍` 小标题 + `list-disc` 列表。

### 3.3 台词卡（DialogueCard）

- 按场分组：`场 {sceneNo}` 小字锚点标题，下方台词行。
- 每行：`角色名`（紫字加粗）+ 情绪徽标（muted 小字 `（情绪）`）换行显示台词正文；`kind=旁白/独白` 时在角色名后加灰色小标签；`action` 存在时以 `（动作：…）` 灰色斜体附在台词后。
- 长台词正常换行，行间紧凑（`space-y-1`）。

### 3.4 分镜卡（StoryboardCard）

- 顶部：`第一集 · 分镜表（J 镜 · 总时长 Xs）`。
- 逐镜列表（不用 HTML table，360px 内用卡片式行更稳）：每镜一个浅灰底小块 `rounded-lg bg-canvas/60 p-2`：
  - 首行：`镜 {shotNo}` 加粗 + 景别徽标 + `场{sceneNo}` + 右对齐 `{durationSec}s`。
  - 画面动作：正文一行（line-clamp 可展开由浏览器自然换行）。
  - 台词：有则 `角色：台词`（violet/80）；空镜显示灰色 `— 空镜 —`。
  - 运镜：`运镜：{camera}` muted 小字；角色用顿号连接的小字。

### 3.5 阶段胶囊

system 居中小胶囊（沿用 SystemPill），紫底白字「进入 STAGE 2 · 剧本分镜」。

### 3.6 进度 / 错误 / 确认门

完全沿用 feature-002/003：spinner/✓/✗、红边错误卡（可重试）、GateCard 三按钮结构。三条进度文案：

- 「编剧 Agent 正在拆分第一集分场…」
- 「编剧 Agent 正在撰写第一集台词…」
- 「编剧 Agent 正在编排第一集分镜…」

重做态文案分别前缀「正在按你的意见重新…」。

## 4. 确认门视觉（2-a / 2-b / 2-c）

| 门 | 标题 | 摘要 | Harness |
|---|---|---|---|
| 2-a | 分场确认 | 共 N 场 · 预估总时长约 Xs | 场数 ≥3 / 每场节拍非空 / 出场角色非空 |
| 2-b | 台词确认 | 覆盖 K 场 · M 句台词 | 覆盖全部分场 / 每场有台词 / 说话人可识别 |
| 2-c | 分镜确认 | 共 J 镜 · 总时长 Xs | 镜数 ≥ 场数 / 总时长 60–120s（软提示）/ 场号引用存在 |

- 2-a details：场次节拍明细（场号 + slug + 节拍列表，可滚动）。
- 2-b details：按场预览台词前若干行。
- 2-c details：镜头简表（镜号/景别/场/时长）。
- Harness 不通过项不阻塞确认（软校验，人可放行）。

## 5. 交互规范

- 1-b 锁定后 CTA 常驻，直到进入 STAGE 2；进入后编剧 Agent 自动推进分场，用户不填字段。
- 否决路径：关门后在对话输入调整意见，回车作为修改指令（用户文本气泡上屏 + 对应产物重新生成 + 重弹同门）；交互与 feature-002 v1.1 / feature-003 重做机制一致。发送路由按 `redoGate / storyRedo / scriptRedo` 优先级判定。
- 请求期间禁用发送按钮；Enter 发送 / Shift+Enter 换行 / 新消息自动滚底，全部沿用。
