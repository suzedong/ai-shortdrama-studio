# SDG-OD-设计说明 · feature-005-产物变更传播

> **版本**：v1.4（2026-10-03，取代 v1.3；六要素含画幅，立项单候选卡与 0-b 门同步显示画幅行）
>
> 设计稿：无外部稿，以本文为视觉/交互验收依据。色板沿用 tailwind.config.js（violet #6C5CE7、ok #2BB673、warn #E8A93C、muted #8A8FA3、line #E8E9F0、danger #E5564E）。

## D1. 节点上的入口

done 节点 hover 时节点卡右侧出现小图标按钮（图标+tooltip，无文案胶囊）：

| 节点 | hover 入口 |
| :-- | :-- |
| 创意输入 | ✎ 编辑　💬 对话修改 |
| 故事背景 | 👁 查看/编辑　💬 对话修改 |
| 立项单/大纲/小传/分场/台词/分镜 | 💬 对话修改 |
| 选题诊断 | 无 |

- 图标按钮 24px 高、muted 色、hover violet；多按钮间距 4px；
- **门控**：loading / 门开着（pendingGate≠null）/ activeUnlock≠null / activeDraft≠null 时全部隐藏（背景「查看」在 activeDraft/activeUnlock 期间保留且只读）；节点处于 invalidated 时不显示修改入口（只显示「重新生成」主按钮）。

节点失效态（invalidated）：节点卡描边 warn 虚线，角标 warn 圆点；卡体下方主按钮「重新生成」（violet 实心），runnable=false 时 disabled 并在 tooltip 说明原因（"请先完成上游：{前驱名}"）。

## D2. 创意编辑弹层（IdeaEditDialog）

- 520px 模态；标题「编辑创意输入」；
- 一个 textarea（min-h 140px），预填当前创意全文（ideaText，来自 replay，初始流程为首条气泡文本）；
- 底部：左侧次要文字「保存后下游将标记失效，需手动重新生成」；右侧「取消」「保存并标记重做」（violet）；
- 保存成功即关闭弹层（不发任何模型请求）。

## D3. 档案模态（BackgroundArchive 变体）

- 复用现有右栏面板组件，后期入口用 640px 模态壳承载（首次填写仍走右栏不变）；
- props：initialText（来自 archive:read 磁盘全文）、busy、viewOnly、onSave、onClose；
- 预填磁盘全文；纯查看（viewOnly 或未改直接关）不产生任何消息/状态；
- 有改动时主按钮文案「保存并触发重做」；未改动 disabled。

## D4. @ 引用 chip 与输入区草稿态

点「💬 对话修改」后：

```
┌──────────────────────────────────────────────┐
│ ┌────────────────────┐                       │
│ │ @ 分场          ×  │  ← chip：warn 描边     │
│ └────────────────────┘                       │
│ 正在修改「分场」。新版需采用并过门后才会生效。  │  ← 提示行 muted 12px
│ ┌──────────────────────────────────────────┐ │
│ │ 输入修改意见…                             │ │
│ └──────────────────────────────────────────┘ │
│              [🎲 重摇一版] [发送]             │
└──────────────────────────────────────────────┘
```

- chip：白底 warn #E8A93C 描边 1px、圆角 16px、高 28px、文字 13px；× 点击＝放弃修改（push revision/cancel，候选卡留存标「已放弃」）；
- 「🎲 重摇一版」仅 AI 源显示（次要按钮）；创意/档案源隐藏（文本改写必须有意见）；
- 此态发送走 draft 路由（契约 §5.2）；activeUnlock 期间整个输入区禁用并提示「请先完成当前变更链」；
- chip 期间画布节点入口全部隐藏，杜绝并发修改。

## D5. 候选卡

### D5.1 人工事实候选（revision-draft：创意/档案）

聊天气泡（agent 侧，白底 line 描边）：

```
┌───────────────────────────────────────────┐
│ 候选 v2 · 未定稿            (warn 描边徽标) │
│ ┌───────────────────────────────────────┐ │
│ │ 改写后的全文（等宽换行，档案 max-h 400 │ │
│ │  可滚动）                              │ │
│ └───────────────────────────────────────┘ │
│ [放弃]              [继续修改] [采用这版]  │
└───────────────────────────────────────────┘
```

- 「继续修改」= 聚焦输入框（不产生新请求）；「采用这版」violet 实心；
- 采用后：该卡徽标转为 ok「✓ 已采用 v2」，按钮全部消失；旧创意气泡即时标注「历史版本」（见 D8）；
- 放弃后徽标变 muted「已放弃」，按钮消失；
- **仅当前 activeDraft 的最后一条候选卡显示按钮**；历史候选卡只读。

### D5.2 AI 产物候选（candidate=true）

- 完全复用对应产物的正式卡组件（视觉风格卡/大纲卡/小传卡/分场卡/台词卡/分镜表），卡顶加一条 warn 虚线条：「候选 vN · 未定稿，采用后需过门确认」；
- 卡不出现「采纳并继续」CTA（那是 GateCard 的事），卡底固定四按钮：
  [放弃] [🎲 重摇] [继续提意见] [采用这版（violet）]
- 采用后：该卡徽标变 ok「✓ 已采用，等待过门确认」，按钮消失；App 同时补发正式产物消息（正式卡紧随其后，正常样式无徽标）并打开 GateCard；
- GateCard 在草稿采用后门否决：GateCard 关闭，输入框恢复 @ chip（提示「已回到修改对话」），候选卡按钮**不恢复**（已采用的候选保持 ok 标记，用户继续发意见会生成新的候选 vN+1）。

### D5.4 立项单候选卡（@ 立项单 · 0-c 源）

- 复用 0-c 门内的立项单版式：上半**六要素表**（题材/平台/单集/集数/基调/画幅，修订字段 warn 高亮）+ 下半**视觉风格块**（形态/家族/主画风/辅画风/锚点词/质感配方/可行度）；
- 卡顶 warn 虚线条：「候选 vN · 未定稿，采用后需过门确认」；风格块右上角徽标「按《视觉风格谱系》提取 · v1.45」（muted 底，版本号取 CATALOG_VERSION）；
- 若意见只涉六要素，风格块无变化时折叠为一行「视觉风格未变动（{主画风}）」；
- 按钮同 D5.2 四按钮；采用后正式卡同版式无徽标，0-c 门按此版式展示；
- 目录外输出：不产生候选卡，聊天流 error 卡「画风不在《视觉风格谱系》目录内，请换个说法（如指定家族或形态）」+ [重试]。

### D5.3 徽标与按钮状态规则（实现判定）

| 情况 | 徽标 | 按钮 |
| :-- | :-- | :-- |
| activeDraft 的最后候选 | warn「候选 vN · 未定稿」 | 全部显示 |
| 同 draft 更早候选 | muted「候选 vN」 | 隐藏 |
| 已采用（其后有正式产物/gate） | ok「✓ 已采用」 | 隐藏 |
| draft 已 cancel | muted「已放弃」 | 隐藏 |
| 孤儿候选（replay 无 draft 上下文） | muted「候选 vN」 | 隐藏 |

## D6. 变更事实卡（unlock 消息）

- system 消息渲染为居中小卡（max-w 480px）：line 底、warn 左竖条、13px；
- idea：「✎ 创意已修订 · 诊断起 7 项已标记失效，请到失效节点重新生成」；
- background：「✎ 背景档案已修订 · 大纲起 5 项已标记失效」；
- AI 源（过门时）：「✓ {产物}已重新定稿 · 下游 N 项已标记失效」（N=0 时改「本剧修改链已全部完成」）。

## D7. 对话流中的「重新生成」与转段

- 失效节点的「重新生成」按钮在画布节点卡上（D1）；runnable 时 violet 实心，非 runnable disabled；
- 跨段 CTA（0-c→故事、1-b→剧本）沿用现有卡片样式，变更链上同样由对应门 confirm 后出现；
- 起跑生成中的节点 loading 样式沿用现状；聊天流滚动到最新消息。

## D8. 历史版本视觉

- superseded 集合内消息：整体 opacity-60、卡左上 muted 角标「历史版本」（11px、line 底色块圆角 4px）；
- 创意旧气泡：第一次 idea-unlock 后，首条 user 文本气泡加同样角标（后续修订依次标更早的；实现：除与 ideaText 相等的最近创意文本气泡外，全部标注）；
- 候选卡任何时候都不标历史。

## D9. 版本归档（主进程，无 UI）

- 旧文件在「重新定稿的 save」前移动到 `会话目录/版本/<base>.<YYYYMMDD-HHmmss><ext>`，同秒 .1/.2；
- 归档后不发消息、不弹提示；本次保存返回的 archived 路径仅在错误排查日志出现；
- 后续版本查看 UI 不在本期。

## D10. 空/异常态文案

| 场景 | 文案 |
| :-- | :-- |
| revise-text 返回空 | 「改写结果为空，请换个说法再试」（error 卡，草稿保留） |
| 画风目录外 | 「画风不在《视觉风格谱系》目录内…」+ [重试]（STYLE_NOT_IN_CATALOG，草稿保留，不产生候选卡） |
| 候选生成失败 | 「生成失败（{原因}），可重新发送意见」+ [重试]（重发上一条意见） |
| 档案读取失败 | 模态内错误态「档案读取失败」+ [重试]；对话入口禁用并提示 |
| draft 中尝试普通发送 | 不发生（发送键已路由到 draft） |
| activeUnlock 中输入框 | 禁用，提示「变更链进行中：先在失效节点重新生成并过门」 |

## D11. 视觉验收要点（真机截图核对）

1. 创意节点 hover 出现两个小按钮；诊断节点任何状态无入口；
2. 编辑弹层预填正确、保存后弹层关闭、诊断节点变 warn 虚线+「重新生成」、无任何模型请求发出（Network 无请求）；
3. @ chip 态：chip、提示行、重摇按钮的显隐（AI 源有/人工源无）、× 放弃后徽标变化；
4. 候选两轮：v1/v2 徽标序号正确，v1 按钮消失；v2 采用前下游节点纹丝不动、Network 只有生成候选的请求；
5. AI 候选采用：ok 徽标、正式卡+GateCard 出现；confirm 后旧卡变「历史版本」、下游失效、旧文件出现在 `版本/` 目录；
6. 门 reject：回到 chip 态、再出 v3、采用、confirm 全链路；
7. 中断重开（采用后未 confirm、候选中未采用、失效未起跑）三处状态恢复一致；
8. 首次完整创作流程（创意→分镜）走一遍：自动连跑节奏、CTA、右栏档案首次填写与现状完全一致（回归红线）；
9. 立项单候选：五要素修订字段高亮、风格徽标版本号、只改集数时风格折叠行、采用→0-c 门整体展示→confirm 后 brief.json 五要素已更新且大纲起失效。
