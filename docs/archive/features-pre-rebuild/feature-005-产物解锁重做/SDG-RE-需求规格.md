# SDG-RE-需求规格 · feature-005-产物变更传播

> **版本**：v1.4（2026-10-03；在 v1.3 基础上将画幅（横屏 16:9 / 竖屏 9:16）并入立项要素，术语改为「立项六要素」）
>
> 用户决策时间线：
> - 第一轮：硬失效强制重走；覆盖全部 8 门点；旧文件归档保留
> - 第二轮：创意可编辑；诊断/五要素是随创意变化的自动物，无手动入口；背景档案可查看/编辑；只标失效、手动起跑；AI 结构化产物不支持直接改文字
> - 第三轮：创意有两种改法——**点开直接编辑** 与 **@ 到聊天框对话修改**；对话产出须**采用后生效**；其他产物也支持对话修改但方式按产物性质分两族；AI 产物**过门确认后下游才失效**（候选迭代期旧版始终有效）；AI 产物统一对话入口，取消"一条意见弹窗立即重做"
> - 第四轮：**立项单、五要素可以对话改**（五要素初值仍自动派生，定稿后作为立项单一部分随 @ 立项单 修改）；**视觉风格不是对话随便改**——必须从《AI短剧制作视觉风格谱系》提取（4 形态 × 18 画风，选 1 主 + 可选 1 辅，锚点词/质感配方照抄目录），不得目录外自由发挥
> - 第五轮（本版）：**画幅（横屏 16:9 / 竖屏 9:16）是立项级决策**，影响分镜构图与后续视频规格；并入要素改称**立项六要素**，按目标平台自动派生（抖音/红果/快手/视频号→竖屏，B站/YouTube→横屏，认不出默认竖屏），0-b 门确认可改、后期随 @ 立项单 对话修改；修改走同一变更传播链
>
> 本规格回答：谁、在什么场景下、要做什么、达成什么效果。

## 1. 业务真相（设计依据）

```
创意(人工) → 诊断(AI，只吃创意) → 六要素(前端由创意+诊断派生，含画幅)
          → 视觉风格(AI，从谱系提取) → 立项单落盘(六要素+视觉风格)
背景档案(人工，0-c 后首次填写)
立项单+档案 → 大纲(AI) → 小传(AI) → 分场(AI) → 台词(AI) → 分镜(AI)
```

每棒 Agent 读取上游全部定稿（[main.ts](file:///Users/szd/Documents/Code/ai-shortdrama-studio/electron/main.ts) / [session.ts](file:///Users/szd/Documents/Code/ai-shortdrama-studio/electron/session.ts) 已证实），改任何上游，其后每棒必须重新生成。

| 族 | 成员 | 修改方式 |
| :-- | :-- | :-- |
| 人工事实 | 创意输入、背景档案 | **直接编辑** 或 **@ 对话改写**（候选采用后生效）；保存后下游标失效，手动起跑 |
| AI 结构化产物 | 立项单（六要素+视觉风格）、大纲、小传、分场、台词、分镜 | **@ 对话迭代**：多轮候选，采用→重开确认门→过门后旧版归档、下游失效；视觉风格必须从《视觉风格谱系》目录提取 |
| 自动物 | 选题诊断 | 无修改入口；只吃创意，创意变了才重诊断 |

六要素（题材/平台/单集时长/集数/基调/**画幅**）初值由创意+诊断自动派生，其中**画幅按平台推定**；定稿后**没有独立入口**，作为立项单的组成部分随 @ 立项单 对话修改（首次流程中在 0-b 门内走既有意见重做）。画幅随变更链传播：改画幅 → 立项单重过门 → 大纲起失效重走；分镜/台词等下游 prompt 一律显式携带画幅（构图按画幅描述）。

## 2. 用户故事

### US-1　创意：直接编辑

画布「创意输入」done 节点 hover 有「✎ 编辑」。点开是当前创意原文，可看可改；保存后：聊天流出变更卡、诊断起全部节点标失效，**不自动生成**；诊断节点出现「重新生成」，手动起跑。

### US-2　创意：@ 对话修改（本轮新增确认）

点「💬 对话修改」，聊天输入框挂上引用「@ 创意输入」。我输入"把女主改成转学生，家庭条件普通"，Agent 基于原文改写，返回一版**新创意候选全文**（不是诊断、不触发下游）。我可以：

- 继续说"再加上她和男主是青梅竹马"→ 候选 v2（多轮）；
- **[采用这版]**：等同 US-1 保存——创意替换、下游失效、手动起跑；
- **[放弃]**：原文不变，零副作用。

中途关掉应用再开，引用态与候选仍在，可继续或放弃。

### US-3　背景档案：查看、直接编辑、@ 对话

「故事背景」done 节点有「查看/编辑」与「💬 对话修改」：

- 查看/编辑：打开预填**磁盘全文**（不是空模板）；只看直接关无副作用；改完点「保存并触发重做」→ 旧档案归档、大纲起 5 个节点失效、手动起跑；
- 对话修改：@ 背景档案 → 自然语言指令（"给男主补一条海外留学四年"）→ Agent 返回新档案全文候选，多轮调整后采用；采用动作等同直接编辑保存（归档+失效）。

### US-4　AI 产物：@ 对话迭代，过门才生效

分镜定稿后我要改分场。「分场」节点点「💬 对话修改」→ 输入框挂「@ 分场」：

1. 我说意见 → Agent 返回**完整新版分场候选卡**（标「候选 v1 · 未定稿」）；此时旧分场仍定稿、台词/分镜仍有效、磁盘文件不动；
2. 我可继续提意见出 v2/v3，或发「重摇一版」（不带意见）；
3. 满意点 **[采用这版]** → 候选转正、重开 2-a 确认门（过门之前一切仍可反悔：门里否决=回到对话继续改）；
4. **门确认的瞬间**：旧分场文件归档、新版落盘，台词/分镜标失效，手动逐棒「重新生成」；
5. 放弃修改：定稿原样。

### US-5　人物小传 id 变化

小传候选过门后，分场/台词/分镜失效；逐棒重生成，speakerId 等引用全部指向新小传，无悬空引用。

### US-6　中断与恢复

- 创意/档案改了没起跑、AI 产物候选迭代中未采用、生成失败：重开应用均恢复——失效态/草稿引用态/候选卡与按钮/旧文件完好；
- 永远不自动调模型（除我显式发送意见或点「重新生成」）。

### US-7　立项单（六要素 + 视觉风格）：对话修改，风格从谱系提取

立项单定稿后我要改集数、换画风。「立项单」节点点「💬 对话修改」→ 输入框挂「@ 立项单」：

1. 我说"集数改成 16 集，画风换成 3D，改横屏"→ Agent 给出**完整立项单候选**（六要素 + 视觉风格一体）：六要素按我的话改写（含画幅）；视觉风格从谱系目录中选定（形态 ∈ 4 形态、主画风 ∈ 18 画风，可选辅画风 ∈ 备选 7 项），锚点词与质感配方**照抄目录对应行**，卡面标注「按《视觉风格谱系》提取」；
2. 若我的意见只动六要素（如只改集数或只改画幅），Agent 原样保留视觉风格，仅在确实影响风格时才调整；
3. 候选可多轮迭代；采用 → 重开 0-c 门；门确认 → brief.json 归档落盘（含新六要素），大纲起 5 节点失效，手动起跑；
4. Agent 给出目录外画风 = 无效输出，报错重试，绝不落盘。

## 3. 发起源与级联表（8 源）

| # | 源（节点） | 入口 | 采用/过门后失效的下游（downstream） | phase | 第一棒 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| S1 | 创意输入 | 编辑 / 对话 | 诊断、立项单、大纲、小传、分场、台词、分镜 | initiating | 诊断（手动） |
| S2 | 故事背景 | 查看编辑 / 对话 | 大纲、小传、分场、台词、分镜 | story | 大纲（手动） |
| S3 | 立项单（六要素+视觉风格） | 对话 | 大纲、小传、分场、台词、分镜 | initiating | 视觉风格（采用即过门） |
| S4 | 故事大纲 | 对话 | 小传、分场、台词、分镜 | story | 大纲 |
| S5 | 人物小传 | 对话 | 分场、台词、分镜 | story | 小传 |
| S6 | 分场 | 对话 | 台词、分镜 | script | 分场 |
| S7 | 台词 | 对话 | 分镜 | script | 台词 |
| S8 | 分镜表 | 对话 | —（无下游，不发 unlock） | script | 分镜 |

规则：

1. **失效发生点**：S1/S2 在「采用/保存」时；S3-S8 在候选「采用」并**过门确认**时；候选迭代期间零失效、零归档、零下游影响；
2. 失效后**手动起跑**：每个失效节点在其直接上游重新定稿后出现「重新生成」；每棒都要手动发起、每道门人工确认；跨阶段沿用「进入故事/剧本创作」CTA；首次全新流程的自动连续行为不变；
3. 诊断无任何修改入口；六要素初值随创意派生、修订随 S3 立项单；0-a/0-b 门只由 S1 间接触发；
4. 背景档案已锁定时，S1 重走到 0-c 过门后不弹档案面板，直接「进入故事创作」CTA；
5. 修改会话（draft）期间禁止其他变更入口与自由聊天，输入框只服务当前 @ 会话，可随时放弃。

## 4. 验收标准

- **AC-1** 节点入口：创意「编辑 + 对话修改」；背景「查看/编辑 + 对话修改」；立项单/大纲/小传/分场/台词/分镜「对话修改」；诊断无入口；pending/active/loading/门开着/有草稿或失效链时入口正确禁用。
- **AC-2** @ 引用：点对话修改后输入框挂 chip「@ {产物名}」（可 × 放弃）；此态发送走修改路由，不进入普通聊天。
- **AC-3** 创意/档案对话：候选为纯文本新全文，可多轮（上下文连贯）；采用前无 Agent 生成下游、无文件写入、无节点状态变化；采用等同直接保存。
- **AC-4** AI 产物对话：候选是完整结构化产物卡（带「候选 vN · 未定稿」标记），可多轮/重摇/放弃；采用前旧定稿与下游一切不变；采用后重开对应确认门，门否决可回到对话。
- **AC-5** AI 产物过门：门确认时旧文件归档、新文件落位、下游立即 invalidated；2-c 无下游不发 unlock。
- **AC-6** 手动起跑：S1/S2 采用后与各级联链过门后均无自动生成；runnable 判定（在 downstream 内 ∧ invalidated ∧ 直接上游 done ∧ 同段 ∧ 无门 ∧ 非 loading）准确；首次流程自动连跑零回归。
- **AC-7** 归档：重新定稿（含 brief.json、故事背景档案.md、各 JSON/MD）旧文件移 `版本/<base>.<时间戳><ext>`，同批时间戳一致、同秒序号；manifest 不归档；首次写入不归档。
- **AC-8** 历史版本：被取代的旧产物卡/旧创意气泡保留可读，呈「历史版本」弱化样式；候选未采用前旧卡不标历史。
- **AC-9** 恢复：草稿进行中（含多轮候选）、已采用未起跑、生成失败三种中断重开后状态正确、不自动调模型。
- **AC-10** 真机：S1（两法各一遍）、S2、S6、S8 全链路；CTA 转段；档案跳过；小传 id 变化无悬空引用；首次流程与门内否决重做零回归。
- **AC-11** 谱系约束：视觉风格输出（首推与候选一致）形态必 ∈ 谱系 4 形态、主/辅画风必 ∈ 18 画风（辅仅限「备」），锚点词/质感配方照抄目录对应行，卡面标「谱系 v{版本}」；目录外输出报 `STYLE_NOT_IN_CATALOG` 不落盘；六要素修订随立项单候选一体提交，0-c 过门后 brief.json 与 0-b 展示同步。
- **AC-12** 画幅：deriveFiveElements 按平台派生（抖音/红果/快手/视频号→竖屏 9:16；B站/YouTube→横屏 16:9；认不出→竖屏）；0-b 门与立项单卡显示画幅行；@ 立项单 可改画幅并随候选一体过门；大纲/分场/台词/分镜 prompt 显式携带画幅（构图描述按画幅）；旧会话 brief.json 无画幅字段 → 运行时回退「竖屏 9:16」显示与 prompt，不回写磁盘。

## 5. 不做什么

- AI 产物的直接文字编辑、单场级局部修改；
- 诊断修改入口；五要素独立入口（随立项单修改）；谱系目录管理 UI（谱系升级人工同步代码内快照）；版本 diff/回滚 UI；一般产物查看浮层（档案查看除外）；
- 候选之间的并排 diff（用聊天流上下滚动对照）。
