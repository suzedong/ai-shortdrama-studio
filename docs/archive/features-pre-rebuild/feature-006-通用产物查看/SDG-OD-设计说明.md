# SDG-OD 设计说明 · feature-006 通用产物查看

> 版本：v1.4（2026-10-04 再修订：清空对话后以定稿文件回退渲染，见 §7）
> 设计依据：《短剧Agent平台设计.md》§画布/确认门；《docs/design/短剧Agent平台-原型.html》；MiniMax Design「点击节点 → 查看/定位」。

## 1. 设计原则

1. **查看是最高频、最低风险动作**：给最大点击目标（整卡），零写入、随时可用；
2. 修改是有副作用动作：收敛到 hover 动作区 + 查看模态底部，受门控约束；
3. 视觉与现有画布一致：浅白底、紫主强调、圆角 10–14px、克制阴影。

## 2. 交互结构

```
节点卡片（done/invalidated）
├─ 整卡点击 ───────────────→ 只读查看模态
└─ hover 右上角动作区
   ├─ 👁 查看  → 同上（stopPropagation）
   ├─ ✎ 编辑  → 既有编辑（idea）
   └─ 💬 对话修改 → 既有 startDraft
```

- pending/active 节点：无 cursor-pointer、无 👁，整卡不可点；
- invalidated 节点：卡片沿用琥珀虚线描边，仍可点查看旧版。

## 3. 查看模态规格

| 区域 | 规格 |
| :-- | :-- |
| 遮罩 | 黑色/深紫半透明，点击关闭 |
| 模态宽度 | 720px（表格类 scenes/storyboard 可至 820px），最大高度 85vh，圆角 14px |
| 头部 | 节点标题（15px 加粗）+ 右侧状态徽标；关闭 × |
| 状态徽标 | done：绿底「✓ 当前定稿」；invalidated：琥珀底「⚠ 已失效·旧版本」 |
| 主体 | 复用聊天流富卡片；padding 20px；overflow-y auto；字号沿用卡片 |
| 底部 | 右对齐：「关闭」次按钮 + 「去修改」紫主按钮（不可用时置灰，title 显示原因） |

## 4. 新增只读段

- diagnosis 只读段：对标案例表（名称/平台/评分/洞察）、用户洞察、钩子模式、合规风险、结论；字段对齐 TopicDiagnosis；底部附创意简报；
- visual-style 只读段（VisualStyleView）：形态/主画风/L2 锚词/L1 世界/质感配方/锚点词 + 可选 family/feasibility；
- idea：whitespace-pre-wrap 文本块。

### 4.1 立项单复合结构（修订）

```
立项单查看模态
├─ 创意简报（BriefCard）        类型/集数/时长/画幅/风格 —— 与画布卡片摘要、选题诊断底部一致
├─ 分隔小标题「视觉风格」
├─ VisualStyleView             形态/主画风/L2锚词/L1世界/质感配方/锚点词…
│                              （若尚未生成：灰字「视觉风格尚未生成」）
├─ 分隔小标题「选题诊断结论」   （diagnosis 不存在时整段省略）
│  ├─ conclusion 原文（可做判定）
│  └─ 对标案例精简表：名称 / 平台·成绩 / 一句启示
```

- 三段自上而下，段间 12px 间距 + 小号灰色分隔标题，不使用分割线卡片感；
- 目的：点开内容与未点开的卡片摘要不产生错位；聚合诊断结论后无需跳转即可看到"为什么可做、参考了谁"，对齐《安妮的夏天》立项单结构；
- 诊断完整内容（用户洞察/钩子模式/合规风险）仍只在「选题诊断」节点，摘要段不重复展示。

## 5. 视觉验收标准

1. done/invalidated 节点 hover 时整卡有可点反馈（cursor:pointer + 现有 hover 阴影增强）；
2. 动作图标仅在 hover 卡片时浮现，位置不随内容跳动；
3. 查看模态信息层级清晰：标题 → 状态 → 内容 → 操作；
4. 失效查看必须有明确「旧版本」视觉提示，避免误当当前结论；
5. 「去修改」不可用时有可见的置灰态，hover 显示原因；
6. 无新增花哨配色/动画，保持与 MiniMax 式克制风格一致。

## 6. 真机验收

在 Electron 中分别对三阶段：点卡片本体打开、点 👁 打开、Esc/遮罩关闭；失效节点查看旧版；门控中查看；去修改各路由。

## 7. 定稿文件回退态（v1.4）

清空对话（消息流无产物）后，查看器与画布回退渲染会话目录下的独立定稿文件；**复用本文件既有全部视觉规格，不新增 UI 结构**，仅数据来源与可查看范围变化：

1. 可回退节点（brief/outline/profiles/scenes/dialogue/storyboard）点开后与正常查看视觉一致，状态徽标固定为绿底「✓ 当前定稿」（定稿文件语义即当前定稿，无失效回退）；
2. 标题右侧来源标注由 `chat.messages.json` 变为对应定稿文件名（如 `来源：brief.json`、`来源：剧本/故事大纲.json`），这是用户区分"消息流产物 / 定稿回退"的唯一视觉线索；
3. brief 立项单回退时：创意简报 + 视觉风格段正常；「选题诊断结论」段只显示 conclusion 原文，**无对标案例表**（不落空表、不显示"暂无案例"占位，直接只渲染文本）；
4. idea、diagnosis 为硬边界：清空后画布节点不补 done（保持不可点），查看器无入口；
5. 回退产物「去修改」沿用既有按钮样式，路由到对应对话修改草稿。

### 7.1 回退态视觉验收

- 回退查看与正常查看在布局、字号、间距上零差异，不出现"降级/恢复"类额外提示条；
- 来源文件名必须真实反映读取的定稿文件，不得仍标注 chat.messages.json；
- 诊断结论段无案例时不得渲染空表格或破版。
