## 1. 背景与问题

视觉风格谱系（[style-catalog.ts](../../../electron/style-catalog.ts)，CATALOG_VERSION=v1.45）是 0-c 选型的唯一事实源。校验链：子模型（工具内 Ark 调用）按 `VISUAL_SYSTEM` 输出 VisualStyle JSON → `parseVisualStyle` → [`assertInCatalog`](../../../electron/style-catalog.ts#L176-L183) 严格等值比对 → 目录外抛 `STYLE_NOT_IN_CATALOG` → 工具返回 `failed()` 信封（feature-013 已保证该信封上屏）。

现存三类缺陷（均为主进程侧，非编排层）：

| # | 缺陷 | 位置 | 后果 |
| :-- | :-- | :-- | :-- |
| 1 | **严格等值匹配无表示噪音容错**：`FORMS.includes` / `s.name === v.mainStyle`，空格/全半角/间隔号/大小写任一差异即拒 | [style-catalog.ts L153–173](../../../electron/style-catalog.ts#L153-L173) | `2D漫`、`DV•CCD 数码复古`、`年代胶片(千禧·90s·80s)`（半角括号）等实质合规值被误拒 |
| 2 | **必填字段缺失时文案为「undefined」**：`形态「${v.form}」` 对缺失字段插值得 `undefined` | [style-catalog.ts L155](../../../electron/style-catalog.ts#L155) | 错误文案无信息量，误导排查 |
| 3 | **错误消息不带值域**：主画风错误只说「18 画风之外」；提示词虽有「逐字照抄」但无必填强调、无错例对照 | [style-catalog.ts L159](../../../electron/style-catalog.ts#L159)、[prompts.ts VISUAL_SYSTEM](../../../electron/prompts.ts#L54-L79) | 模型拿不到正确名单无法自纠，用户需翻源码 |

**定调**：谱系目录仍是选择域硬边界——本 Feature 只消除**表示噪音**与**反馈盲区**，绝不把真目录外名称（如「二次元水墨风」「水彩绘本」）吸附到目录内。

## 2. 角色与场景

| 角色 | 场景 | 期望效果 |
| :-- | :-- | :-- |
| 创作者 | 0-c 改部分要求「2D漫」（无空格）等表示变体 | 工具识别为 `2D 漫`，产物卡展示**规范名**，无失败 |
| 创作者 | 要求真目录外风格（二次元水墨风/赛博朋克工笔画） | 仍失败，但错误气泡含**完整 18 画风名单（主/备分组）**，可直接从中挑选重发 |
| 创作者 | 子模型漏输出必填字段 | 错误文案明确「未输出」，不再出现「undefined」 |
| 子模型 | 生成 VisualStyle JSON | 提示词明确字段必填、给出常见错例对照、要求目录外诉求取目录内最接近项并在 rationale 披露 |

## 3. 功能需求

### F1 · 名称归一匹配（B1）`[自研新增]`

- F1-1 新增确定性归一函数，作用于 **form / mainStyle / auxiliaryStyle 三个名称字段的比对**：NFKC 归一（全角 ASCII/括号→半角）→ 间隔号 `•・` 统一为 `·` → 去除全部空白字符 → 小写化。输入与目录名**双侧同规则归一**后比对。
- F1-2 归一仅用于匹配，**不做语义映射**：归一后仍不相等即判目录外。
- F1-3 归一零碰撞为契约守护项：4 形态 + 18 画风名归一后须两两唯一（测试固化）。
- F1-4 命中的匹配值**回写为目录规范名**（canonicalization）：产物/manifest/UI 永远携带目录原文（如 `2D 漫`），不残留模型变体。

### F2 · 必填字段缺失文案 `[自研新增]`

- F2-1 form / mainStyle 缺失（undefined/null/空白串）时，校验原因为「未输出」语义并附该字段的合法值域，**不得出现 `undefined` 字面量**。
- F2-2 auxiliaryStyle 为可选字段，缺席不视为缺失（沿用现状）。

### F3 · 错误消息回传值域（C2）`[自研新增]`

- F3-1 主画风不在目录时，错误消息附 **11 主 + 7 备完整名单**（分组标注）。
- F3-2 辅助画风错误（不在目录 / 非备档）时，消息附备档 7 项名单。
- F3-3 形态错误消息保留现有 4 形态名单；缺失时同样附 4 形态名单。
- F3-4 `STYLE_NOT_IN_CATALOG` 错误码与「视觉风格不在谱系目录（v1.45）：」前缀不变；`failed()` 信封结构不变。

### F4 · 提示词强化（C1）`[自研新增]`

- F4-1 `VISUAL_SYSTEM` 追加（**只增不改**，既有语句全部保留）：① 必填字段清单与非空要求（auxiliaryStyle 按规则可选）；② 常见错误对照（如 ❌`2D漫` → ✅`2D 漫`、❌`赛博朋克` → ✅`赛博·科幻`、❌`仿真人动漫` → ✅`拟真人·仿真人动漫`）；③ 用户要求目录外风格时禁止自造新名，须选目录内最接近项并在 rationale 披露「用户原要求 X，目录内最接近为 Y」。
- F4-2 `buildVisualStylePrompt` 签名与 user 段不变。

## 4. 不做什么（边界）

1. **不做 B2 别名表**：不维护 `二次元→2D 漫` 等语义映射；任何语义映射须用户逐条拍板后另行立项。
2. **不做 B3 就近吸附**：不引入编辑距离/模糊匹配自动吸附。
3. **不做 C3 工具内部自愈重试**：失败仍即返 `failed()` 信封，重试由导演模型/用户发起。
4. 不改 `ok()/failed()` 信封结构与错误码；不改 `parseVisualStyle` 解析逻辑；JSON 解析失败的 mock 降级路径不变。
5. anchorWords / qualityRecipe 仍仅非空校验（feature-005 既定规则，不扩张为逐字校验）；family / feasibility / l2Anchor / l1World 不新增校验。
6. **不修改 `shared/types.ts`**（无 K1）；不新增文件模块之外的改动（无 K6，全部落在既有三个文件）；零新增依赖（无 K9）；无 IPC / UI / 持久化结构变化。

## 5. 验收标准（AC，任务清单 AC 表为准）

- AC-1 表示变体命中并回写规范名：`2D漫`、`2Ｄ 漫`（全角 D）、` 2D 漫 `（含首尾空格）均判定为 `2D 漫`，且校验通过后的产物值为规范名 `2D 漫`。
- AC-2 画风名变体命中：`年代胶片(千禧·90s·80s)`（半角括号）、`DV•CCD数码复古`（•间隔号无空格）命中对应目录项并回写规范名。
- AC-3 真目录外不误吸：`二次元水墨风`、`水彩绘本` 仍判定目录外。
- AC-4 缺失文案：form 缺失时原因含「未输出」且不含 `undefined`；mainStyle 缺失同理。
- AC-5 值域回传：主画风错误消息含全部 11 主 + 7 备画风名；辅助画风错误消息含备档 7 项名单。
- AC-6 提示词强化生效且不回归：`VISUAL_SYSTEM` 含必填约束、错例对照、目录外诉求处理三条新增内容；[revise-text.test.ts](../../../src/test/revise-text.test.ts) 既有断言（谱系版本/禁止目录外/照抄目录/18 项注入计数等）全部保留通过。
- AC-7 归一零碰撞：4 形态与 18 画风名归一后两两唯一（测试守护）。
- AC-8 回归与手动验证：typecheck / test（只增不减）/ build 全绿；手动回归——0-c「改部分」发 `2D漫` 变体：工具成功、产物卡显示规范名；发真目录外名：错误气泡含 18 项名单。
