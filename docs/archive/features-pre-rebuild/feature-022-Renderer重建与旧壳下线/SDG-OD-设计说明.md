# SDG-OD 设计说明 · feature-022 Renderer 重建与旧壳下线

> 状态：**v1.0 待签字**
> 日期：2026-10-08
> 无新建 B 类可视化稿；布局对齐 feature-016 OD §1–§3。视觉语言（圆角卡片、`border-line`/`bg-canvas`/`text-ink`/`text-muted` token）全部沿用 studio 既有组件。

---

## 1. 布局：两栏 → 三栏（对齐 016 OD §1）

```
┌────────────┬──────────────────────────┬──────────────────┐
│ 左栏        │ 中栏 CanvasBoard          │ 右栏              │
│ ProjectNav │  八步节点泳道分组          │ ChatComposer      │
│ ·项目列表   │  点击节点→StudioViewer    │ ·消息流           │
│ ·新建/打开  │                          │ ·GateCardView内联 │
│            │                          │ ·输入框           │
└────────────┴──────────────────────────┴──────────────────┘
```

1. 顶栏保留：左侧"短剧创作工作台 + 项目名"；**删除"返回旧版"按钮**，右栏不再放任何切换入口。
2. 栅格：`lg` 起三栏（左栏固定约 `w-56`，中栏 `flex-1`，右栏约 `w-[26rem]`）；`<lg` 单列堆叠（导航 → 画布 → 对话）。
3. 三栏同高 `min-h-0`，各自内部滚动，页面级不滚动。

## 2. 左栏 · ProjectNav（新）

1. 结构：标题"项目" + 列表 + 底部"新建项目"按钮。
2. 列表项：项目名一行省略；当前项目高亮（`border-violet bg-violet-soft`）；点击进入。
3. 空态：无项目时显示引导文案 + 新建按钮。
4. 新建：行内输入项目名 + 确认（沿用 `project:create` 的最小参数）；不做高级表单。
5. 错误：list/open/create 失败在栏内顶部红字提示，不影响其余两栏。

## 3. 中栏 · CanvasBoard（增量）

1. 分组泳道、节点卡、auto 边、状态色——**全部不动**（feature-020/021 验收态）。
2. 增量：有 `ref.path` 的节点卡可点击——hover 出 `cursor-pointer` 与浅色描边变化，点击 `onOpenNode(node)`。
3. 有 pending 门时相关节点脉冲高亮（016 OD §2.5）——若既有实现已含则不动，未含则本切片补上（以 `canvas.gates` 中 pending 门关联节点为准）。

## 4. StudioViewer（新，只读）

1. 形态：中栏内覆盖层（不占新栏），标题 = 节点 `kindLabel + title`，右上角关闭。
2. 内容头：`ref.path` + 格式徽标（JSON / MD）。
3. 内容体：JSON 美化等宽渲染；MD 纯文本等宽渲染（不引入 MD 渲染器）。
4. 态：加载中 / 内容 / 错误提示（含 `file:read` 拒绝 message）三态。
5. 无任何编辑控件、无保存按钮。

## 5. 右栏 · ChatComposer + GateCardView（不动）

消息流、流式态、门卡内联、输入框、错误气泡——全部沿用 019-021 验收态。仅容器从半宽变为右栏定宽。

## 6. 视觉验收标准

1. 桌面宽度三栏齐平、间距一致（`gap-4`）、同高；左栏不挤压中栏节点卡横向滚动。
2. 节点点击反馈明确（hover 态），点击后 viewer 出现且画布仍在背景可见。
3. 门 pending 时右栏门卡内联呈现，节点脉冲（若 §3.3 适用）。
4. 全界面无"返回旧版"入口；无旧壳组件样式残留。
