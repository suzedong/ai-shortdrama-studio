## 1. 判定口径

### 1.1 来源标签

- **[Design 原有]**：参考产品已有的用户可见功能或核心交互；本项目自主实现，不复制闭源代码、商标、私有素材、账号权限或云端服务。
- **[改编]**：保留参考能力目标，但按桌面本地优先、纯 JSON、局域网 ComfyUI、固定媒体通道或八步闭环调整形态 / 数据 / 权限。
- **[自研新增]**：为局域网媒体、完整短剧生产体系、证据追溯等本项目目标新增，不冒充参考产品原有能力。

### 1.2 当前状态与最终结论

当前状态只描述 P0 可证事实：

| 状态 | 含义 |
|---|---|
| **已有基础，未 Parity 验收** | 有实现或任务包证据，但尚未按本矩阵完成形态、数据、异常和真机对账。 |
| **部分对齐** | 仅部分子能力有实现或证据；不得由局部通过推断整域完成。 |
| **待复刻** | 已纳入路线，尚无完整实现；后续必须独立建包或修订既有包。 |
| **待产品裁决** | 存在产品取舍、在线服务或边界选择，未逐项获得用户批准。 |
| **自研闭环待实施** | 本项目必须补齐的短剧产物链，不计入参考产品已有完成度。 |

P7 最终每行只能转为：**已复刻 / 改编通过 / 经决策不纳入**。最终结论必须附 Feature 任务包与测试 / 真机证据；“有 UI”“有依赖”“参考模板存在”“单次演示成功”均不等于通过。

### 1.3 通用改编边界

| 维度 | 参考形态 | 本项目现行形态 | 影响 |
|---|---|---|---|
| 数据 | 云端账号、项目及本地 SQLite 等参考实现 | 本地项目目录 + 纯 JSON，无数据库 | 不照抄 SQLite / 云 Schema；需定义 JSON 版本、恢复、引用与迁移。 |
| 文本 Agent | 云端模型及专有 Agent 编排 | 火山方舟 / LM Studio 二选一；OpenCode / MCP；系统优先 | 不复用专有提示词；角色、工具和权限需逐包映射。 |
| 图像 / 视频 / 音乐 | 云端多模型矩阵 | 仅 H3 Image / H3 / Music3，全部经本地 / 局域网 ComfyUI | 不开放模型选择矩阵；需显式提示能力差异和不可用项。 |
| 语音 | 参考在线声音能力 | 通道待定 | 未裁决前不得绑定 T2A / 其他服务或完成 STAGE 6 声音验收。 |
| 在线服务 | 账号、团队、社区、会员、积分、支付、云同步 | 默认评估本地替代或经决策不纳入 | 具体项见 §3；不得伪造登录、发布、支付或同步成功。 |
| 操作系统 | 参考桌面 / 云协同形态 | Electron 桌面应用，Renderer 不直连 ComfyUI | 媒体、密钥、文件和权限统一收敛于主进程 / MCP。 |

## 5. 维护规则

1. 新 Feature 建包或范围变化时，先更新对应行的目标包、影响和待决门，再实施；共享类型、接口、依赖仍分别走 K1 / K8 / K9。
2. 当前实现和验证结论只引用任务包 / 证据，不在本文复制日志、测试计数或环境实时状态；P0 点态结果见基线报告。
3. 历史 Qwen、豆包 / T2A 等描述只作为当时事实保留；现行行必须指向 H3 Image / H3 / Music3 与“语音待定”。
4. 参考文档升级或新增运行时补证时另起矩阵版本并记录差异，不回写 v1.5 及更早参考文档或 v4.0.8 macOS 的历史实测快照。
5. 任何“经决策不纳入”必须链接到用户明确决策；本版在线待决清单不得直接作为不纳入凭证。
