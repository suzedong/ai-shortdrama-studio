03

IPC / MCP 通道（2026-10-09 磁盘实况）

对话统一走 runtime 单轨；旧 8 个 ark 直连对话 IPC 已快照后删除。以下为 main.ts 现存 25 个 invoke 处理器（均经 preload 白名单暴露），反向补录认定尚未完成。

项目 / 应用 4 通道

  • project:list / create / open项目库 3 通道
  • app:config-status方舟配置状态

runtime 12 通道

  • runtime:start / stop / status生命周期
  • runtime:session:create / list会话管理
  • runtime:session:abort / delete中断 / 删除
  • runtime:prompt · prompt:async发送（流式 / 异步）
  • runtime:event:subscribe / un-事件推送
  • runtime:agent:listAgent 目录

画布 / 门 / 资产 / 文件 6 通道

  • canvas:get / subscribe / un-画布读取与推送
  • gate:decide门裁决
  • asset:list资产枚举
  • file:read产物只读

ComfyUI 设置 + MCP 端点 3 + HTTP

  • settings:comfy:list / upsert / remove多实例配置
  • MCP /mcp（POST/GET/DELETE）JSON-RPC · SSE · Bearer · loopback

MCP 侧现存 11 个纯工具（file.read / canvas.get / gate.request / asset.register / comfyui.instances 等），由 electron/mcp/tools.ts 注册；注意 resources/opencode/agents/*.md 中的放行名仍写 shortdrama_*，与实际工具名不一致，待反向补录时一并认定。

媒体引擎硬边界

ComfyUI 是统一媒体引擎：图像 / 视频 / 音乐全部以权重 / 工作流在本地或局域网推理。

本地 / 局域网 ComfyUI（多实例 · 地址可配）

媒体生成零公网 · 无云端 Key · 无按次费用
qwen-image
图像通道唯一模型（人物 / 场景 / 关键帧）
MiniMax H3
视频通道唯一模型（图生视频 / 镜头）
MiniMax Music3
音乐通道唯一模型（配乐）

红线：Agent 不得自行切换其他图像 / 视频 / 音乐模型；语音通道待定。renderer 不直连 ComfyUI，媒体调用一律经 MCP / 主进程引擎工具（B0 / B5 / B8 / B9）。
