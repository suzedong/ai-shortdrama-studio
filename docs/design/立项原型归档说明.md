## 3. 现行立项 UX 在哪里

**所有立项 UX 看 [短剧Agent平台-原型.html](./短剧Agent平台-原型.html)**：

- 左栏顶部 toggle 切到"流程导航"或 STAGE 0 步骤点击 → 进入 view-stage0
- 中栏 view-stage0：4 步流程导航 + 进度条 + 入口卡 + 3 列节点链（含风格选型 + 辅助开关 + 缺口追问）+ 定案门弹层
- 顶栏 `▶ 观看式演示` 按钮 → 5 步串行自动推进（v1.9 原型的自动播放模式在主原型内嵌）
- 顶栏 `↺ 重置流程` → 清空状态回 step 0

## 4. 何时需要 git 历史找回 v1.9 / STAGE0

仅以下场景需要：

1. **研究立项 UX 演化路径**——看"4 节点 4 门 → 1 入口 2 节点 1 门 → 全可改影响评估"的三轮迭代
2. **对比演示形态**——v1.9 的 450ms 串行节奏与主原型的"chip 即时推"虽然都能演示过程，但节奏感不同
3. **写立项 UX 教学文档**——把旧版视觉作"反例"截图

**否则一律用主原型**。
