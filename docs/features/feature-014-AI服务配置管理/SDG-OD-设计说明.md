# SDG-OD-设计说明 · feature-014 AI 服务配置管理

> 配套 [SDG-RE-需求规格.md](./SDG-RE-需求规格.md) / [SDG-RE-契约.md](./SDG-RE-契约.md)。本说明冻结面板形态与控件分层；视觉验收以本文件 + 契约为准。

## 1. 入口

rail 底部 AI 圆标既有系统菜单（`data-sys-menu-root`）：菜单项列表尾部增「AI 服务设置」，与「使用指南」「导出」同列同风格；点击后关闭菜单、打开模态面板。

## 2. 面板形态（冻结）

模态对话框（与既有门卡/确认弹层同一遮罩体系），宽度约 520px，标题「AI 服务设置」。

| 区块 | 控件 | 口径 |
|---|---|---|
| 状态行 | 文本徽标 | 「AI 服务：可用 / 未配置 / 连接失败」——与对话区横幅同一数据源（保存后复检刷新） |
| API Key | `type=password` 单行输入 + 「清除 Key」次按钮 | 占位符显脱敏值（如 `sk-1234••••abcd`）或「未配置」；输入框留空保存 = 不动；清除按钮仅已配置时可点，点击后输入框置「将清除」待保存态，随保存生效 |
| Base URL | 单行文本输入 | 占位显默认 `https://ark.cn-beijing.volces.com/api/v3` |
| 模型名 | 单行文本输入 | 占位显「如 doubao-…」；空值保存 = 清除 |
| 来源标记 | 每字段右侧小号灰字 | 「自定义 / 环境变量 / 默认」三态之一 |
| 高级 | 折叠区（默认收起，chevron 旋转动画从简） | 三项：端口探测起点（数字输入，占位 4096）/ 健康检查超时 ms（数字输入，占位 10000）/ mock 引擎地址（文本输入，占位 `http://127.0.0.1:4099/v1`）；折叠区标题右侧注「改动需手动重连运行时生效」 |
| 错误条 | 面板内顶部红条 | IPC `INVALID_ARGUMENT` 等错误文案原样上屏；出现错误条时面板保持打开 |
| 操作行 | 「取消」次按钮 + 「保存」主按钮 | 保存中主按钮 loading 禁用；成功后：无 runtime 变更 → 直接关闭；含 runtime 变更 → 面板内提示「运行时参数已保存，需手动重连运行时后生效」并提供「重连运行时」与「关闭」，重连成功后仅保留「关闭」 |

## 2A. 固定服务商扩展（D-022 · 终局口径）

- 标题下、状态行上增加「AI 服务商」单选下拉，选项固定为「火山方舟」「LM Studio」；没有新增、删除、自定义服务商按钮。
- 选择火山方舟时保持 §2 既有 API Key / Base URL / 模型名形态；选择 LM Studio 时仅显示 Base URL 与模型 ID，默认地址占位 `http://127.0.0.1:1234/v1`，不显示 API Key 控件。
- 两个服务商的配置在切换编辑时不清空；保存当前服务商切换或 LM Studio 配置后，面板驻留并显示「服务商配置已保存，需手动重连运行时后生效」，操作行提供「重连运行时」主按钮与「关闭」次按钮。
- 不自动重连、不新增模型列表拉取或连接测试按钮；仅点击「重连运行时」后复用既有 `runtime.stop()` → `runtime.start()`，重连中按钮 loading 禁用，成功后提示「运行时重连成功，配置已生效」并仅保留「关闭」，失败在既有错误条上屏且允许重试；仍由主进程统一校验，renderer 不直连服务商。

## 2B. 对话输入区模型选择器

- 选择器置于输入框下方既有工具行，位于 Skill / 资产按钮之后、「H3 自动选配」之前；使用原生 `select`， accessible name 为「对话模型」，沿用既有 24px 高紧凑控件、细边框与小号字体，不新增图标或设计 token。
- 选项文案为「火山方舟 · {模型ID}」「LM Studio · {模型ID}」；长模型名在可用宽度内截断，原生展开项仍显示完整名称。
- 无可用模型时显示「请先在 AI 服务设置中配置模型」，选择器与发送按钮禁用；输入草稿保留，用户仍可打开设置面板。
- 切换只影响后续消息，不弹出确认、不重连运行时、不清空当前草稿或历史消息。

## 3. 交互纪律

- 明文 Key 永不回显：password 框初始为空，占位符仅显脱敏；
- 保存成功必调既有 `checkAiHealth` 复检（feature-808 D-013 链路），对话区横幅随结果消隐；
- 所有校验在主进程（契约 §2.2）；renderer 仅做空值提示性辅助，不重复实现校验规则（防双口径漂移）；
- 风格沿用 StudioApp 既有弹层/表单控件类名体系，零新 UI 依赖、零新设计 token。
