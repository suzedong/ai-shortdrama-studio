# feature-813 工作目录更换 · 设计说明

> 有 UI 变化（新增设置面板 + 系统菜单项），按任务包 5 文件要求提供本设计说明。
> 视觉验收以本文为准；形态完全沿用 feature-014 `AiServicePanel` 的既有面板体系，不引入新设计语言。

## 1. 入口

- 系统菜单新增「工作目录」菜单项，与「AI 服务设置」并列（`data-sys-menu-item="workspace-settings"`）；
- 点击：关闭菜单、打开「工作目录」模态面板（与 AI 服务设置同一交互模式）。

## 2. 面板形态（`WorkspacePanel.tsx`，新组件）

模态结构 = 标题「工作目录」+ 关闭按钮 + 主体 + 底部操作区，与 `AiServicePanel` 同骨架。

### 2.1 主体

1. **当前根目录行**：
   - 绝对路径（等宽字体展示）+ 来源徽章：`自定义` / `默认`（映射 `source: 'store' | 'default'`）；
   - `data-workspace-root` 标记。
2. **更换区**（初始态）：
   - 「更换目录」按钮（`data-workspace-change`）；
   - 点击 → 调 `window.api.settings.workspace.pick()`：
     - `dir === null`（用户取消）→ 无任何动作，不提示；
     - `dir` 非空 → 进入确认态。
3. **确认态**：
   - 目标路径展示；
   - 提示行：「将整体移动 N 个项目目录」（N = `window.api.listProjects().length`，进入确认态时取一次）；
   - 按钮：「确认更换」（`data-workspace-confirm`）、「取消」（回到初始态）；
   - busy 中（change 请求在途）：两个按钮均 disabled。
4. **成功条**（`changeDir` resolve 后）：
   - 文案：`已更换到 {root}（移动 {movedCount} 个项目）`；
   - 固定提示行：「运行时已驻留时，需手动重连运行时后新根目录生效」（与 feature-014 runtime 保存提示同语义）；
   - 当前根目录行刷新为新值；更换区复位到初始态。
5. **错误条**（`data-workspace-error`）：
   - 主进程 message 原样上屏（剥 `Error invoking remote method …` 壳，复用 `AiServicePanel` 的 `ipcErrorMessage` 模式）；
   - 面板保持打开，确认态保留已选目标目录（可点「确认更换」重试，或「取消」放弃）。

### 2.2 底部操作区

- 「关闭」按钮；无其他常驻按钮（更换动作集中在主体确认区）。

## 3. 文案（冻结，测试断言依据）

| 位置 | 文案 |
| :-- | :-- |
| 菜单项 | 工作目录 |
| 按钮 | 更换目录 / 确认更换 / 取消 / 关闭 |
| 确认提示 | 将整体移动 {n} 个项目目录 |
| 成功条 | 已更换到 {root}（移动 {n} 个项目） |
| 运行时提示 | 运行时已驻留时，需手动重连运行时后新根目录生效 |
| 错误条 | 主进程 message 原文（契约 §2.4 文案为准） |

## 4. 视觉验收

- 面板与 AI 服务设置面板同骨架同字号体系（标题、正文 12.5px、按钮样式一致）；
- 三态可观测：初始态（仅更换目录按钮）/ 确认态（目标 + 双按钮）/ busy（按钮禁用）；
- 错误态：面板不关闭、已选目标不丢失、错误条红色语义色（沿用 `text-bad` 体系）；
- 成功态：成功条绿色语义色（沿用 `ok` 体系）+ 当前根目录行即时刷新。
