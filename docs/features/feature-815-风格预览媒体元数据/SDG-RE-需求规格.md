# feature-815 风格预览媒体元数据 · 需求规格

> Feature：feature-815-风格预览媒体元数据 ｜ 模块：8xx 跨阶段平台基础 / 视觉风格谱系
> 版本：v1（2026-11-14）｜ 状态：实施及真机验收完成；包外测试与运行时基线如实保留
> 溯源标签：[自研新增]
> 上游：用户「这里只显示了视频，应该图片和视频都显示；图片和视频的提示词和参数要能从图片和视频获取」；原实施计划已获批准，批准结论已固化于本任务包，工具侧重复计划已清理。
> 既有落点：feature-802 / 811 谱系面板；本包不改写其已封闭契约。

## R-001 · 图片与当前档视频同屏

风格详情弹窗中，参考 PNG 与视频 MP4 不再互斥。宽窗口为双列、窄窗口为单列；图片始终独立显示。标准 / turbo / FastH3 三档只切换视频，不切换、隐藏或重新请求图片。缺图、缺视频或播放失败只影响自身区域。

## R-002 · 元数据必须来自各自媒体文件

点击图片或视频，各自从该文件内嵌 ComfyUI 元数据读取提示词与生成参数。PNG 读取 `tEXt` 中 keyword 为 `prompt` 的 API graph；MP4 只沿 `moov → udta → meta → keys/ilst` 读取 `mdta.prompt`。禁止全文件搜索 `"prompt"` 猜 JSON，禁止从画面 OCR / AI 反推。

## R-003 · 只展示文件实值

图片展示可识别的正 / 负提示词、seed、steps、CFG、sampler、scheduler、denoise、画幅、模型文件；视频展示运动提示词、首帧文件名、seed、steps、采样参数、画幅、帧数、fps、模型文件。以文件 graph 为准；没有记录的字段省略并统一说明「未列出的字段未记录」，不得从档名推断步数，不得用谱系锚点词 / 质感配方冒充媒体提示词。完整提示词可复制。

## R-004 · 主进程封闭读取

renderer 不接收任意路径、不读文件、不直连 ComfyUI。主进程仅接受注册 styleId、封闭媒体类型与档位，复用 `loadStyleCatalog().sourcePath` 定位同目录 `_style_preview`，按注册家族目录与白名单文件名映射读取。使用 `resolve + relative + realpath`、扩展名、符号链接 / 路径逃逸检查及元数据大小上限；不向 renderer 返回绝对路径或完整 graph。

## R-005 · 分源降级与快速切换

图片、视频分别维护加载 / 成功 / 失败状态。文件缺失、无内嵌元数据、格式不支持或内容损坏均诚实说明，媒体仍尽量显示，不拖垮目录与另一媒体。快速切档或关闭重开时，旧响应不得覆盖新选择；失败文案不含绝对路径或原始异常。

## R-006 · 谱系信息分源

保留「锚点词示例 / 质感配方」，置于明确的「谱系信息」区域，与「文件内嵌生成信息」分开展示。本包不修改谱系 Markdown、注册表含义或十键目录 DTO。

## 非目标

任意路径导入；MKV/WebM；转码、ffmpeg；从画面反推提示词；修改 PNG / MP4 / 谱系；新增媒体模型、依赖或 ComfyUI 生成行为。

## 验收

- AC-1：A1 同时存在 PNG 与 MP4 时，弹窗同时渲染 `<img>` 与 `<video>`；三档只改视频 `src`，图片请求不重复。
- AC-2：真实 A1 图片与三档视频的提示词、参数逐项等于各自内嵌 graph；图片与视频内容不串源。
- AC-3：谱系锚点词 / 配方不参与媒体元数据；完整提示词复制文本不截断。
- AC-4：missing / no-metadata / unsupported / invalid 均有独立诚实降级，另一媒体及目录可用。
- AC-5：构造缺字、畸形 box、坏 JSON、超限、UI Format 与路径逃逸反例，解析失败 closed，不读取目录外文件、不泄露绝对路径。
- AC-6：连续快速切换标准 / turbo / FastH3，仅最后选择生效；旧图片 / 视频响应不覆盖新状态。
- AC-7：真实 Electron 目验 A1 双媒体、三档切换、复制与降级；typecheck、Electron build、专项及全量测试执行并记录，既有基线不冒充本包回归。
