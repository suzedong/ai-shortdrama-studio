# feature-817 需求规格：全局双主题与对话形态对齐

> **版本**：v1.0（2026-11-15）｜**状态**：实现已落地，验收中；双主题 Electron 现场通过，AI runtime 交互现场受阻
> **上游**：《短剧Agent平台设计.md》§3.4；用户提供的 MiniMax Design 对话截图
> **决策**：真实形态对齐；保留 feature-001 首问；深色为整个工作台的可切换主题

## 1. 目标与边界

将右侧对话从普通气泡列表升级为“目标复述 → 真实任务详情/思考 → 结构化回答”的任务式对话，并为整个工作台提供浅色/深色主题。只复用现有消息、流式、历史回放、capture/quote 和确认门链，不另建会话存储或演示业务状态。

**不做**：不把首问改为题材；不伪造需求分析、项目规划或 1/3；不改 `shared/types.ts`、Electron IPC、运行时事件、项目 JSON、依赖；不改变 ChipRow 单击直发、GateCard 拍板和画布布局。

## 2. 功能需求

### R1 全局主题

- 顶栏右侧、窗口控制前提供太阳/月亮按钮；默认浅色，二态切换，无 system 第三态。
- `localStorage['studio.theme']` 仅接受 `light | dark`，缺失/非法值回退浅色；首绘前恢复，重启不闪白。
- `<html>` 的 `dark` 类是唯一 DOM 主题开关；按钮具 `aria-label`、`aria-pressed`、焦点态。
- 主题为 renderer UI 偏好，不进入共享类型、项目数据、Canvas、Agent 上下文或 IPC。

### R2 全局视觉令牌

- Tailwind 语义色由 CSS 变量驱动，至少覆盖 `win/canvas/surface/ink/muted/line/violet-soft`。
- 浅色保持现有近白画布；深色使用低反射蓝灰表面、清晰边框和品牌紫强调，不用紫色渐变背景。
- 覆盖顶栏、画布、立项、对话、谱系、受影响、风格弹层、toast、菜单、异常页、滚动条和 Markdown；布局密度不变。

### R3 真实任务详情与等待状态

- 连续工具段聚合为可折叠“任务详情”，保持原事件顺序；每条仍显示 Agent/工具、动作、状态、耗时和错误。
- 任务状态仅由工具终态与 `stream.status` 派生：存在 running=进行中；无 running 且存在 error=执行失败；全部完成=已完成。
- 运行中即使详情被折叠，标题仍保留活跃动画；推理段继续独立折叠。
- 最新未消费选项或 pendingGate 显示“等待回答”；历史只展示实际 `segments/tools`。

### R4 分步选项卡

- 编号 `【选项】` 与 `【风格选项】` 单击只暂存，不立即发送；选项和自定义回答互斥。
- 活跃卡提供关闭/重新展开、自定义输入、下一步；下一步发送所选编号或自定义trim原文，走既有 `onSend`。
- 无答案、busy、非最新项禁用提交；本地提交锁防止双击；发送失败且卡仍活跃时允许重试。
- 回放继续由后续用户消息恢复 picked/disabled；关闭状态只是本地视图状态。
- `【追问选项】` chips 继续单击直发，GateCard 语义不变。

### R5 可选协议元数据

- 纯文本选项块可在开始标签后首行写 `步骤：N/M`；N/M 为正整数且 N≤M，渲染“第 N/M 步”。
- 纯文本选项行可尾部写 `【推荐】`；渲染推荐徽标并从选项正文剥离。发送仍只发编号。
- 元数据仅用于纯文本选项块；缺省不显示，非法则整块回退原文，不静默猜测。
- showrunner 仅在外层流程确有总步数/推荐依据时输出，禁止臆造。

### R6 目标复述与输入区

- 用户给出一句话创意后，showrunner 先简短确认目标和真实制作路径，再提出既有“商业短剧/个人纪念”首问。
- 输入区对齐 MiniMax 的圆角、边框、聚焦与发送层级，保留模型选择、停止、AI 降级和无项目锁定。

## 5. 运行中断展示与证据校准 Change（2026-11-26）

本 Change 消费 feature-808 已批准的 runs/retry IPC，不在本包重复定义接口，不新增视觉需求。

- 仅对 interrupted 轮次的 pending/running 工具显示“已中断”，去掉活跃动画；原始 ToolView 与历史 DTO 不变，completed/error 工具保持原状。
- 引擎无用户消息的 interrupted 运行显示独立“提交结果未知”恢复卡；OptionCard 未提交答案不代选，pending Gate 保持人工拍板，已落盘产物不回滚。
