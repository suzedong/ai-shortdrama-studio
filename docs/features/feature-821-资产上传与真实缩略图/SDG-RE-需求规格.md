# feature-821 · 资产上传与真实缩略图 · 需求规格

> 日期：2026-11-16 ｜ 阶段：P1 切片 C ｜ 溯源：[Design 原有·形态对齐 / 自研新增实现]
> 来源：[P1 调查记录](../../verification/p1-2026-11-15/P1调查记录.md) §3-③；用户已批准实施计划及 K8。

## 1. 问题与目标

资产中心当前只支持 `asset.list`，没有上传入口或项目图片读取通道，图片卡仍以文件名首字母代替缩略图。本包完成：

**原生选择一张图片 → 主进程校验并安全复制到当前项目 → 复用资产索引登记 → 面板刷新 → 显示真实、可重开恢复的 WebP 缩略图。**

上传为系统直做，不经过 Agent；不自动绑定节点，继续复用 feature-814 的勾选与绑定/解绑。

## 2. 范围

- 单文件 PNG / JPEG / WebP；真实格式校验，不凭扩展名信任输入。
- 原图最大 64 MiB、4000 万像素；拒绝 SVG、空文件、损坏/截断图片、目录和符号链接。
- 使用已有 `sharp@0.33.5` 处理 EXIF 方向并生成最长边 320 px 的 WebP 小图。
- 上传图片与既有 ComfyUI 图片共用缩略图读取；旧图按需生成，不批量迁移。
- 非图片资产保留原卡片；缩略图不可用只回退首字母，不影响绑定。
- 项目切换清理旧列表和旧图，异步旧响应不得覆盖新项目。

## 3. 非范围

多选/批量/拖拽上传；视频、音乐、工作流上传及封面；原图查看；资产删除/重命名；对话引用；MCP 工具与画布绑定语义变更；自定义媒体协议；通用二进制 IPC；新依赖、新 E2E 或打包框架。

## 4. 验收标准

| 编号 | 通过判据 |
| --- | --- |
| AC-1 | 真实选择 PNG/JPEG/WebP 后，原图位于当前项目 `资产/上传/`，索引仅有对应一条记录，meta 完整且无源绝对路径。 |
| AC-2 | 图片卡显示真实 WebP 缩略图，DOM `img.complete && naturalWidth > 0`，无 `file://`；重开项目后仍恢复。 |
| AC-3 | 取消选择零文件、零索引变化、无错误提示；失败不伪造列表或成功 Toast。 |
| AC-4 | 同内容重复上传保持同 ID/路径且不重复登记；坏索引不被按空索引覆盖。 |
| AC-5 | 非法格式、超限、符号链接和路径逃逸被拒绝；缩略图失败仅当前卡片降级。 |
| AC-6 | 既有 ComfyUI 图片无新增索引字段也可按需生成真实缩略图。 |
| AC-7 | 上传中防重入；项目切换后旧上传、列表、缩略图响应不污染新面板。 |
| AC-8 | 四类页签、搜索、勾选、绑定/解绑回归通过；上传本身不写 `canvas.command`。 |
| AC-9 | K1/K9 零触发；K8 恰两个新 IPC，三端及 dev-mock 同步。 |
| AC-10 | typecheck、构建、专项测试与真实 Electron 证据入档；既有全量失败基线单列，不伪报全绿。 |
