# feature-821 · 资产上传与真实缩略图 · 需求规格

> 日期：2026-11-16 ｜ 阶段：P1 切片 C ｜ 溯源：[Design 原有·形态对齐 / 自研新增实现]
> 来源：[P1 调查记录](../../verification/p1-2026-11-15/P1调查记录.md) §3-③；用户已批准实施计划及 K8。

## 1. 问题与目标

资产中心当前只支持 `asset.list`，没有上传入口或项目图片读取通道，图片卡仍以文件名首字母代替缩略图。本包完成：

**原生选择一张图片 → 主进程校验并安全复制到当前项目 → 复用资产索引登记 → 面板刷新 → 显示真实、可重开恢复的 WebP 缩略图。**

上传为系统直做，不经过 Agent；不自动绑定节点，继续复用 feature-814 的勾选与绑定/解绑。

## 2. 范围

- 单文件 PNG / JPEG / WebP；真实格式校验，不凭扩展名信任输入。
- 原图最大 64 MiB、4000 万像素；拒绝 SVG、空文件、损坏/截断图片、目录和符号链接。
- 使用已有 `sharp@0.33.5` 处理 EXIF 方向并生成最长边 320 px 的 WebP 小图。
- 上传图片与既有 ComfyUI 图片共用缩略图读取；旧图按需生成，不批量迁移。
- 非图片资产保留原卡片；缩略图不可用只回退首字母，不影响绑定。
- 项目切换清理旧列表和旧图，异步旧响应不得覆盖新项目。

## 3. 非范围

多选/批量/拖拽上传；视频、音乐、工作流上传及封面；原图查看；资产删除/重命名；对话引用；MCP 工具与画布绑定语义变更；自定义媒体协议；通用二进制 IPC；新依赖、新 E2E 或打包框架。

## 5. D-037 现行归并约束：可信资产来源（2026-11-19）

本包现行职责扩展为 **“资产入库、可信来源与真实缩略图”**，接收归档包 814 §6 / §7 的可信来源部分。上传仍是系统直做，不自动绑定节点；Canvas 命令和绑定 UI 由 823 负责，对话资产引用由 822 独立负责。

1. 资产记录可携带可信来源：`sourceJobId` 仅来自成功作业工具的真实 `jobId` 参数，`sourceSession?: { sessionId, messageId, callId }` 仅来自运行时真实完成事件，二者均为可选，不要求历史资产回填。
2. MCP `asset.register` 只新增可选入参 `sourceJobId`；**不得新增或接受 Agent 自报 `sourceSession`**，不得接受自报任务 ID、消息 ID 或完成事件。物理工具名只认 `shortdrama_asset_register`，display name / action label 不得作为识别依据。
3. 运行时须在调用过滤或分类前取得 `tool.call` 事件。仅同时满足 tool 精确匹配、结果结构为成功 JSON、存在真实已登记资产 ID、事件 sessionId / messageId / callId 三元组完整时，才补写来源；非 JSON / 缺字段 / JSON null 结果均跳过。
4. 任务来源从两类受支持 `resultPreview` 形状读取：直接 `{assetId, jobId}`，或 `{text: '<json>'}`。禁止用当前 `activeSessionId` 反推历史事件，禁止在缺三元组时猜消息归属。
5. 来源补写只对已存在资产执行，缺失或非法 ID 不得造空记录；坏索引继续按损坏处理，不得转空数组。重复资产登记继续保留既有来源，允许省略 `sourceJobId / meta / sourceSession`，不得以空值覆盖。
6. 来源补写失败仅记录安全日志：不回滚已经完成的媒体资产，不取消完成事件，不阻断 SSE，不伪造“来源已关联”成功。
7. 上传导入仍只经原生选择与系统校验；导入成功不自动绑定 Canvas 节点。可信来源不扩展为历史会话导航、删除任务联动、同步改 Agent 任务状态、局域网实时推送或通用历史补写。

**冲突裁决**：§3 的“MCP 工具与画布绑定语义变更”仍是首次上传切片的非范围；本节只收编 814 已批准的 `sourceJobId` 可选入参与运行时来源补写，不授权本轮新增 MCP / IPC。原“无新增索引字段”仅指缩略图派生路径设计，来源字段的后续批准事实按契约 §6 单列，历史 K1/K8 与验收记录不改写。
