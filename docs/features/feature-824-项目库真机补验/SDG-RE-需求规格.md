# SDG-RE-需求规格 · feature-824 项目库真机补验

> 日期：2026-11-17 ｜ 档案类型：标准 5 文件档 ｜ 溯源：**[自研新增 · 既有能力真机补验]**
> 上游：[P1 调查记录](../../verification/p1-2026-11-15/P1调查记录.md) §5 切片 F、[D-015](../../governance/SDG-AI-决策台账-2026.md)、[已批准实施计划](../../../.trae/documents/切片F-项目库真机补验实施计划.md)
> 当前状态：矩阵执行完成；AC-F1—F9 通过，AC-F10 / F824-01 未闭环，验收整体不通过。

## 1. 背景与用户价值

项目改名、删除和异常目录回退已有实现及自动化，但真实系统废纸篓恢复、标题同步、异常项目打开时的 Renderer/主进程状态一致性尚无完整真机证据。本切片用一次性隔离项目补齐这些证据，使用户能够知道现有项目库在常见异常下是否安全、哪些行为仍只是既有缺口。

本包是**验收包，不是功能修复包**。发现缺陷时保存最小复现并如实登记，不顺手修改产品代码，不把“补验执行完成”写成“全部通过”。

## 2. 既定行为边界

- 改名只修改 `.session.json` 的显示别名，不改物理目录。
- 当前项目禁止删除；UI 禁删之外，主进程仍须以 `PROJECT_ACTIVE` 拒绝。
- 删除使用 Electron `shell.trashItem` 进入 macOS 系统废纸篓；恢复通过 Finder“放回原处”，仓库没有应用内恢复入口。
- 缺失/坏 JSON 的列表回退不等于项目修复或可打开；坏 manifest、session、canvas 必须分别记录实际行为。
- 打开失败且原项目继续保持当前，与打开返回成功但主进程和 Renderer 分属不同项目，是两类不同结果；后者属于串项目缺陷。

## 3. 验收标准

| AC | 验收内容 | 通过判据摘要 |
| --- | --- | --- |
| AC-F1 | 当前项目改名 | UI Enter 提交；侧栏、顶栏、立项标题同步；session 新名 trim；目录、manifest、业务数据不变；切换及完整重启后保留。 |
| AC-F2 | 非当前改名与取消 | 非当前改名不影响当前项目；随后打开标题正确；Esc 取消零写盘。 |
| AC-F3 | 删除取消与当前拒删 | 取消目录不变；当前项 UI 禁删，真实 IPC 返回 `PROJECT_ACTIVE`，目录未移动。 |
| AC-F4 | 非当前真实删除 | 唯一一次性项目经 UI 二次确认删除；原目录消失，系统废纸篓定位同一项；前后哈希可核对。 |
| AC-F5 | Finder 恢复 | Finder 对同一项“放回原处”；原路径和内容恢复；完整重启后列表可见、可打开、标题和画布正确。不得以 `mv` 替代。 |
| AC-F6 | 缺 manifest | 列表不崩溃并记录回退；打开明确失败且 `currentDir`、当前画布保持原项目。列表可见不可打开只记既有行为。 |
| AC-F7 | 坏 manifest | 不崩溃、不静默覆盖坏文件、主进程与 Renderer 项目一致；若仅降级打开，不写成校验或修复通过。 |
| AC-F8 | 坏 session | 记录列表回退及打开后的五字段重建、title/session 变化；不串会话或项目。降级初始化不等于恢复原绑定。 |
| AC-F9 | 非项目目录与读取失败 | 非 `project-*` 不入列表，直接 IPC 返回 `INVALID_PROJECT_DIR` 且状态不变；隔离注入一次 EACCES 并记录，无法可靠注入则标环境受限。 |
| AC-F10 | 坏 canvas | 坏文件保持原样，`canvas.get` 返回 `CANVAS_CORRUPT`；`currentDir`、DOM 标题和画布标识不得分属两个项目。 |

每条 AC 在证据中标记 `pass / existing-behavior / defect / inconclusive` 之一，并附操作、实际结果、文件/状态快照和证据链接。`existing-behavior` 是补充事实，不自动等价于 AC 通过。

## 4. 非目标

- 不修复 B-70，不处理其 75 项既有失败。
- 不新增应用内回收站、恢复 IPC、项目导入导出、搜索、置顶、历史详情或异常修复向导。

- 不执行 Agent 发送、画布编辑、状态推进或修复性写入来“试探”异常项目。
- 不据此宣告 P1 退出门或 MiniMax Design Parity 通过。

## 5. 安全与完成口径

只操作唯一命名的 `project-f824-*` 隔离 fixture；禁止清空废纸篓、触碰其他 Trash 项或真实用户项目。坏档与权限 fixture 仅在 Electron 完全停止后注入。

最终状态只能是：

1. **补验完成并通过**：全部适用 AC 通过，无缺陷或未决项；或
2. **补验执行完成、登记缺陷/受限项**：矩阵已执行，但至少一项未通过或无法验证；或
3. **受阻未完成**：隔离、数据安全或串项目问题使矩阵无法完成。

详细契约见 [SDG-RE-契约.md](./SDG-RE-契约.md)，执行与证据见 [SDG-RE-任务清单.md](./SDG-RE-任务清单.md)。
