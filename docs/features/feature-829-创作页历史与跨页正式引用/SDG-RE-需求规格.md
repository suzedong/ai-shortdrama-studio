# feature-829 · 创作页历史与跨页正式引用 — 需求规格

> 版本：v1.0（2026-11-19 冻结）｜溯源：[Design 原有·形态对齐] / [自研新增实现]
> 上游：已批准 P1 连续收口顺序、D-035/D-036、Parity 影响矩阵 §1.2/§1.3、feature-823。
> 授权：用户要求按当前收口顺序继续完成 829；本规格不沿用索引中“保持后置”的旧阶段表述。

## 1. 问题

多创作页与多画布已能持久化，但页/画布切换没有浏览器式前进、后退历史，用户跨页检查后只能手动逐页返回。现有“复制产物引用”只复制路径或节点 ID，不能把源产物身份、版本和来源位置作为正式关系落盘；源产物再版后，也无法只提醒实际引用它的节点。

本包的“页历史”是应用内导航历史，不是产物文件版本历史；后者及通用历史记录不在本包范围。

## 2. 目标

1. 在创作页管理条提供后退、前进，记录当前项目内的页/画布目标；新导航截断前进栈，相同目标不重复入栈。
2. 页/画布历史只存于当前应用会话；完整重启恢复既有持久化活动目标，但不恢复前进/后退栈。
3. 用户可从有明确 `meta.version` 的源节点复制正式引用，到另一创作页粘贴为引用节点；引用固定源 `artifactId + version + source target`，并随 Canvas v4 持久化。
4. 源节点通过既有 `canvas.update` 改 `meta.version` 即视为再版；仅匹配来源目标与产物 ID、且固定版本不同的实际引用节点记录最新版和脏标记时间。
5. 引用节点可打开源产物，系统切回源页/画布并打开源节点；源缺失或目标非法时明确报错，不伪造跳转成功。

## 3. 验收标准

### AC-829-1 · 页/画布前进与后退

管理条在空态和非空态均提供可键盘操作的后退、前进按钮及禁用态。页 tab、画布 select、新建页/画布和删除后的有效活动目标按导航语义入栈；同目标无重复项，回退后新导航清空前进栈。历史导航使用既有 `active.set`，不增加 revision/receipts，不重置会话、草稿或资产附件。已删除目标不可复活，回退时跳过失效项；完整重启仅恢复持久化活动目标并新建空历史栈。

### AC-829-2 · 跨页正式引用创建与持久化

源节点必须有 `ref.path`、非空 `meta.version`，且不能本身是引用节点。用户在源节点菜单选择“复制正式引用”，到另一创作页通过空白菜单“粘贴正式引用”；系统在目标画布生成有独立节点 ID 的引用节点，复制展示所需字段，并写入：

- `reference.artifactId = 源节点 id`；
- `reference.version = 源节点 meta.version`；
- `reference.source = 源页/画布 target`。

同页粘贴、缺版本、源缺失、引用链、节点 ID 冲突、非法坐标和跨项目来源均失败且不产生部分写入。命令具备既有 expectedRevision、commandId/hash 幂等语义；引用节点及其固定版本在完整重启后不变。

### AC-829-3 · 再版只挂脏实际引用者

既有 `canvas.update` 只更新其固定目标文档。若其中源节点 `meta.version` 相对旧值改变，主进程扫描整个 Canvas，仅对 `reference.source` 与源目标一致、`reference.artifactId` 与源节点 ID 一致的引用节点写入 `latestVersion`；固定版本与最新版不同的写 `markedAt` 并显示脏态。相同版本更新不挂脏，源节点、同页其他节点、其他来源引用及未引用节点均不挂脏。系统保留既有引用字段，MCP 全量 merge 不得伪造、覆盖或清除系统管理的引用状态。

### AC-829-4 · 引用呈现与源定位

引用节点显示固定版本徽标；源再版后显示最新版提示和独立黄条，不冒用立项 dirty 字段。引用节点菜单提供“打开源产物”，成功后切换活动页/画布并打开源节点查看器；源不存在、版本缺失或导航失败时保留当前位置并显示真实错误。原“复制产物引用”和“引用到对话”的既有行为不回归。

### AC-829-5 · 自动化与真实 Electron 验收

覆盖历史顺序、前进截断、失效目标、重启重置、正式引用创建、全部参数边界、幂等/冲突、重启持久化、再版精确脏标记、MCP 引用状态保护和源定位。定向测试、全量 Vitest、typecheck、build 通过；真实 Electron 完成跨页导航/回退/前进、引用创建、源再版、重启恢复及源定位，保存结构化证据和必要截图。不宣称通用历史、通用版本恢复或完整 Parity 通过。

## 4. 非目标

- 不实现跨项目/全局导航历史、历史栈持久化、时间旅行、产物 Diff Review 或通用撤销重做。
- 不实现产物文件历史面板、版本回滚、跨文件事务或源内容快照；引用节点仍按 `ref.path` 读取源当前文件。
- 不新增边类型、跨页边渲染、引用链、循环引用、自动对齐或批量再生成。
- 不提前实施 feature-830—834，不新增媒体请求，不修改生成通道，不提交、不推送、不发布。
