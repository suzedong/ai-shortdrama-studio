0. 定位

MiniMax Design = AI Agent 驱动的商业内容生产平台：用户表达创作目标 → Agent 规划任务、扩展 Prompt、选择 Skill 与工具、调用适配模型、组织素材、持续修改，把想法做到最终交付。

覆盖内容形态：文本脚本、图文、视频、Motion Graphic、3D 建模、网页 UI/UX、专业设计与影视后期。优势场景：广告投放、电商素材、品牌宣传、KOC 内容、短视频、Motion Graphic、3D 资产、影视后期。

1. 功能全景

1.1 画布式创作界面（官方口径）

区域功能
中间 · 画布内容（含上传文件）自动按流程连线、展示步骤节点；对齐参考线/自动吸附；剪辑后可导出到画布或本地，可让 Agent 代导出
右侧 · Agent 对话与 Agent 对话、画布创作；接入十多款模型，Agent 自动匹配最优、可手动切换
左侧 · Skill/模板/插件官方精选 + 创作者分享的技能与工作流
左侧 · 项目/资产资产中心沉淀角色/场景/风格包/道具，跨项目快速调用

1.2 四种创作入口（官方口径）

  1. 直接描述目标：如"为一款无线耳机制作 15 秒竖屏广告，突出轻便降噪"。
  2. 从 Skill 开始：`/` 快捷键调用 / 与 Agent 询问匹配 / 已开启 Skill 自动调用。
  3. 从提示词模板：模板广场选模板 →「使用提示词」→ 修改 → 生成后继续对话调整。
  4. 导入素材或项目：本地图/视频/音频/3D/历史项目继续编辑；资产中心素材直接调入。

1.3 生成能力（官方口径）

云端模型矩阵：视频 = 海螺 v1/v3、可灵（+唇同步/虚拟人/动作控制）、Veo3、Wan 3.0、Seedance、即梦；图像 = nano_banana/OpenAI/Qwen/seedream/Kling/Midjourney；语音 = TTS/音色/克隆/人声隔离/音频续写；音乐 = 生成/翻唱/歌词；其他 = 媒体分析、超分。

H3 本地部署：FL2VA（文生视频+首/尾帧）/ Ref2VA（全参照：9图+3视频+3音频）；ComfyUI day-0 原生支持（三组件：扩散模型+文本编码器+双 VAE，768p 短边，12GB 可出 480p）；官方精选工作流（轻量/满血/超清/扩写）；服务器部署 vLLM-Omni / SGLang。

1.4 Skill 生态（官方口径）

沉淀四种：① 让 Agent 生成 Skill；② 创作后存成 Skill（/skill-creator）；③ 修改后"保存为我自己的 Skill"；④ 上传资料生成。分享：投稿社区 → 官方审核 → 积分奖励 → 用户精选。内置 9 个官方 skill（实测）：h3-visual-design、cool-music-video、brand-ad 等。

1.5 专业插件与工具（官方口径）

  • 3D 导演台：3D 场景摆放角色素体、调度机位/姿态、可多人，搭分镜参考。
  • 视频剪辑：自然语言加改字幕（内容/时间/位置）、转场/滤镜/贴纸、裁剪拼接排序、比例布局调整。
  • 精品工具：360° 全景预览（固定场景）、重打光（电影级）、多角度（同主体多机位）、多宫格分镜、批量水印/Logo。

1.6 商用、协作与会员（官方口径）

  • H3 社区许可：免版税商用（年收入 ≤2000 万美元 + 标注 MiniMax H3 + AUP；不得用于训练其他非 H3 系模型）。
  • 团队版：创建团队/管理成员/积分池共享（成员单独额度）/团队项目资源共享（开发中）。
  • 会员/积分：年卡 8 折生成优惠。
  • 协作规范：需求 = 表达商业目标；修改公式 = 保留什么 + 修改什么 + 为什么 + 期望结果；质量检查 8 条（商业目标/前三秒/卖点/准确性/品牌统一/字幕/节奏/规格）。

2. 架构实测

本节来自社区实测（Je，2026-08-23，Windows）+ 用户实测截图（2026-10-02），非官方口径，注意时效。

2.1 应用架构（实测 v43.1.0，内部名 @hilo/hub）

层内容
应用本体Electron 应用（com.minimax.hub），内部代号 @hilo/hub
Agent 运行时标准 opencode，MCP 服务指向网关 http://localhost:8001
MCP 工具集mcp-tools/hub_*：画布读写、媒体生成、ComfyUI 工作流管理等
多 Agent 角色router / planner / executor / media-agent / comfyui-agent
ComfyUI 插件bundled-plugins/comfyui/（内嵌完整 ComfyUI 前端，画布节点由此渲染）
本地端口8001 网关 / 8002 工作区运行时 / 10268 内部（均仅 127.0.0.1）
云端能力清单海螺/可灵/Veo3/Wan/Seedance/即梦 + qwen/seedream/Kling/MJ + TTS/音乐/超分等

等效链路（实测）：外部 agent 写 H3 提示词 → 改模板工作流 → POST /prompt → /view 收片，与 Design 内部 comfyui-agent 的 hub_run_comfyui_workflow 同一件事（全本地免费；云端 Context-IR / Regenerate-2K 本地替代不了）。

2.2 ComfyUI 接入实测（重要结论 · 用户截图）

用户实测 设置 → ComfyUI 界面：仅「启动参数」输入框（如 --lowvram、--preview-method auto），界面明文：「端口、数据目录等由 Hub 托管的参数无法覆盖」。

结论：当前版本 MiniMax Design 的 ComfyUI 后端为 Hub 内置托管，设置只允许追加性能参数，端口/监听地址不可配置 → 无法连接局域网内非本机 ComfyUI。此结论以用户实测为准（社区抖音教程曾演示"填服务地址"，疑似旧版本，已不适用）。

3. 与我们体系的对照（可借鉴 / 不可替代 / 不可连）

维度MiniMax Design我们的体系结论
画布自动连线内容自动按流程连线、步骤节点已升级为画布式界面借鉴：画布+状态着色+预览跳转
Agent 任务确认生成前确认参数、制作简报R4 确认门：check 全过+人点 advance同源：Design 软确认 / 我们硬门禁
Skill 沉淀对话流程存 Skill、投稿分享skill 目录 + pipeline 路由借鉴：沉淀为可复用 Skill
修改反馈公式保留+修改+为什么+期望flag 反向回流（归因+受影响传导）互补：公式可并入人机话术
质量检查8 条商业内容检查验收规则.json 30 种检查类型互补：审美/商业 vs 文件/内容级
生成通道云端多模型矩阵R8 红线：2512 + H3 + 豆包 T2A不可替代：红线通道不改
ComfyUI 接入Hub 托管，端口不可覆盖（实测）执行适配层可配置地址 + --listen 0.0.0.0不可连：Design 连不了局域网，自研可以
状态机/溯源无流程状态机、无镜头 json 溯源proj.py 状态机 + 30 种校验 + prompt_id 溯源不可替代：Design 无此层
部署本地部署 Beta（H3 工作流）venv 无 docker 一键启动参考：本地优先一致

结论：Design 适合做"创意发散/云端多模型生产"的参考形态与对照物；我们的工作台定位（画布+内嵌 Agent+规范门禁+可配置 ComfyUI）在当前版本 Design 上无法实现，需自研（见《短剧Agent平台设计》）。
