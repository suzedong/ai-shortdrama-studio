- 这是**用户登记的固定独占拓扑**，不以 API 返回替代 OS 物理设备映射、并发与独占验收。
- 不因端口顺序或各实例均显示 `cuda:0` 自行推断物理 GPU 编号；启动参数声明映射与物理设备实测分别记录。

| `8001` | `0.45.3` / `3.13.12` / `2.12.1+cu130` | `--cuda-device 1` | 一张 RTX 4090 | running / pending 均为空 | [system_stats](./comfyui-8001-system-stats.json) · [queue](./comfyui-8001-queue.json) |

- 三个 `/system_stats` 与 `/queue` 请求均返回 HTTP 200；三实例均监听 `0.0.0.0`，启动参数中的端口与请求端口一致。

- 该次盘点只确认端口、启动设备参数和单卡 API 视图，未取得进程 PID、GPU UUID 或远程 `nvidia-smi`；空队列只是采样时状态。

### 5.3 2026-11-15 H3 Image 逐端口串行任务实测（仅 API 级）

用户选择仅做 API 级验证。本轮使用工作区外验证脚本直接调用三个 ComfyUI HTTP API，串行提交相同受控 H3 Image 工作流的 0.1 MP 测试任务；未经过应用内生产 `ComfyEngine`，未写应用实例配置、项目作业或资产索引。

| 端口 | 启动参数声明 | promptId | 运行队列样本 | 基线可用显存 → 目标最低可用显存（字节） | 输出 PNG |
| --- | --- | --- | ---: | ---: | --- |
| `8000` | `--cuda-device 0` | `56b21d66-5f14-447d-982d-934b8e71b8c5` | 35 | 24,159,191,040 → 114,159,460 | 320×320 / 59,056 B |
| `8001` | `--cuda-device 1` | `515fc7ad-11d1-42fe-a3ed-e8d29a4df48e` | 10 | 24,159,191,040 → 116,374,540 | 320×320 / 60,597 B |
| `8002` | `--cuda-device 2` | `e66a881a-160b-4dbc-927c-10851c2f3673` | 15 | 24,159,191,040 → 115,208,036 | 320×320 / 85,353 B |

- 三次 `requestId → client_id → promptId → 对应端口运行队列 → history.completed` 均匹配，最终一致性校验为 `allPassed: true`；完整 requestId、输出 SHA256 与逐项检查见 [validation.json](../gpu-placement-2026-11-15/validation.json)，时间线与三实例显存极值见 [summary.json](../gpu-placement-2026-11-15/summary.json)。
- 每次目标实例可用显存显著下降时，两个非目标实例在同一运行窗口保持稳定：8000 运行时 8001 / 8002 不变；8001 运行时 8000 / 8002 不变；8002 运行时 8000 / 8001 不变。
- 三个下载结果均通过 PNG 文件头、320×320 尺寸、字节数与 SHA256 校验，哈希互不相同，内容均为可辨识灰色方块。
- **结论边界**：可判定 **API 级逐端口落卡通过**；启动参数声明映射为 `8000 → 0`、`8001 → 1`、`8002 → 2`。该结论不等于已经取得 OS 级物理 GPU 编号、GPU UUID、端口 → PID 或 `nvidia-smi` 证据。

3. 验证三实例并发、GPU 过载与资源争用、单实例故障隔离、超时 / 重连及历史 pending 续查。
4. 分别核验 H3 视频和 Music3 所需节点、权重与工作流；缺失即停止对应验收，不用云通道或 Qwen 回退。
