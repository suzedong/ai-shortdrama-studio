## 7. 对 P2 契约的约束性输入

以下是后续 Feature 建包与契约设计的输入，不是本轮实施授权：

1. **任务身份不能依赖参考端 UI 是否暴露。** 参考端 UI 未显示任务 ID，但本地持久化记录已有任务 ID、`idempotency_key` 字段、`revision` 和 outbox 事件；本项目仍需项目内稳定任务 ID、提供方任务引用、父子任务与重试关系，以及可持久化的完整事件序列。
2. **提交、扣费、运行、结果是不同事实。** 图像异常链证明不能把首次点击、实际扣费和结果出现合并为一个时间戳或单一“成功”事件；需记录请求接受、失败提示、后续扣费和结果回写之间的真实关系。
