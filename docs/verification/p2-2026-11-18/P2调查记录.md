## 6. 对 P2 契约的约束性输入

以下是后续 Feature 建包与契约设计的输入，不是本轮实施授权：

1. **任务身份不能依赖参考端 UI 是否暴露。** 本项目仍需项目内稳定任务 ID、提供方任务引用、父子任务与重试关系，以及可持久化事件序列。
2. **提交、扣费、运行、结果是不同事实。** 图像异常链证明不能把首次点击、实际扣费和结果出现合并为一个时间戳或单一“成功”事件；需记录请求接受、失败提示、后续扣费和结果回写之间的真实关系。
3. **不得由一条扣费流水推断 exactly-once。** 本项目仍须自研防重复提交、幂等键、状态推进去重、孤立输出认领和人工对账；参考端未暴露这些内部机制。
4. **参数快照与实际媒体元数据分开。** 至少保留请求模型、参考模式、比例、分辨率、配置时长、数量、声音、提示词和成本，同时保存实际编码、尺寸、帧率、帧数和时长；UI 展示时长另做格式化。
5. **恢复验收必须拆用例。** “结果已可见后的正常重启恢复”与“排队 / 运行中重启后的续跑、重提交或失败收口”是不同验收项，不得互相替代。
6. **结果回写不等于版本血缘。** 本轮证明结果节点、本地文件、原参数和资产主体可关联；多版本派生、重试版本、失败回滚及完整血缘仍需独立证据。
7. **通知需要独立契约与验收。** 未读数、已读、完成 / 失败事件和深链定位不能因为画布上能看到结果就被视为通过。
8. **参考端云端行为不得搬作本项目媒体通道。** 本项目仍固定 H3 Image / H3 / Music3，经本地或局域网 ComfyUI 执行，Renderer 不直连 ComfyUI；账号、积分、订阅和支付不属于本轮本项目实现范围。
