## 1. 登记与清理规则

1. **一个事实只有一个规范出处**：本表通过链接引用设计或 Feature 契约，不复制其完整规范，也不另写一份“当前实现说明书”。
2. **只登记真实偏差**：须同时有明确规范出处和当前实现差异。尚未到建设阶段的路线能力不算偏差；已实现但待人工验收的事项留在任务包，不自动算偏差。
3. **闭环即移除**：设计与实现对齐并完成所需验证后，删除对应条目。实施过程与历史结论由 Feature 变更记录、根版本记录和 Git 追溯，本文件不保留已解决条目。
4. **编号稳定**：B 编号删除后不重排、不复用；新增偏差从 **B-70** 起登记。若后续新增导致编号变化，只修改下一起始号，不回填历史条目。
5. **内容保持简短**：每条只保留规范出处、当前差异和闭环条件。详细证据、测试输出与修复过程放对应 Feature 任务包。
