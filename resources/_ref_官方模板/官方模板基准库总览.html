02

八阶段选型

阶段产物 × 可复用媒体能力

八阶段是业务产物与验收边界，7 类工作流用途域是可复用媒体能力，二者是多对多关系。阶段定义以《短剧Agent平台设计》为准，不合并、不裁剪。

阶段现行主用按需参考状态与边界
0 立项H3 Image 文生图—风格样片可辅助拍板；生产只走已注册 H3 Image。
1 故事——大纲、人物小传由文本链完成。
2 剧本分场——分场与资产需求由文本链和系统完成。
3 资产H3 Image 文生图H3 Image 编辑文生图已接入；编辑仅参考。多角度、拆层、透明底不再路由到 Qwen。
4 分镜H3 Image 文生图H3 Image 编辑参考图修改可评估 H3 编辑，未接入前不得提交生产。
5 镜头—H3 I2V / T2V / R2V / 多帧参考 / 视频控制全部为参考保留、生产未接入。
6 后期—Music3；H3 Image 编辑配乐与图像编辑均未接入；剪辑、字幕、合流、混音由后期系统负责。
7 发布H3 Image 文生图H3 Image 编辑系统负责成片与渠道交付；封面仅复用现行图像通道。

2.3 质量与返修原则

  1. 图像草案与正式件都使用 H3 Image；通过 prompt、seed、画幅和 MP 管理迭代，不再设置 Qwen Wuli、Lightning 或 Turbo 成本档。
  2. H3 Image 生产采样固定官方参考的 6 步 / CFG 1；本次不新增采样参数面板。
  3. 视频预览与定稿应在同一路由内比较，具体档位待对应视频 Feature 冻结。
  4. 人设漂移先回批准 prompt / 参考与首帧；构图失败先修首帧；接片跳变回最近合格末帧。任何失败都不得触发 Qwen 回退。
  5. 透明底、分层、多角度或严格控制网需求，标记为未覆盖并走人工/系统处理或新 Feature。

08

执行与验收纪律

生产注册优先于模板存在
  1. 生产调用只提供 instanceId / workflowId / requestId / inputs，由主进程加载 manifest；renderer 不直连 ComfyUI。
  2. 任一执行节点或权重缺失时停止，不提交 /prompt；不使用云节点、视频权重或 Qwen 回退。
  3. 每次生成记录资产/镜头 ID、workflowId/version、requestId/jobId/promptId、输入、实际映射、输出与验收结论。
  4. 参考模板升级为生产前必须具备：Feature 契约、API Format 执行件、实例 object_info 核验、受控输入、自动化回归、真实收片与资产登记。
  5. 单次失败先修当前步骤；没有同条件对照与真实证据，不新增主备模型、成本档或组合链。
  6. 当前 10 份 UI 模板与 10 份 API 参考件不改文件名、不改 JSON 字节；Qwen 与本轮三类参考件删除仅限本目录，新增 API 文件仅原样登记。Qwen 生产 graph 只能按 C3 的单独明确授权删除；模型权重、LoRA 与历史资产不得随之删除或改写。
